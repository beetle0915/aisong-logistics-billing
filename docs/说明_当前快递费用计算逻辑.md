# 当前快递费用计算逻辑说明

本文档用于梳理当前系统中“不同快递公司如何根据重量计算快递费用”的实际代码逻辑，方便后续判断是否需要优化计费规则。

当前结论先说清楚：

```text
系统目前不是为每一家快递公司写一套独立公式。
所有快递公司先统一使用：快递费用 = 首重费用 + 续重费用 * 续重重量。
德邦会在公式结果出来后额外做一次整数四舍五入。

不同快递公司的差异主要来自：
1. 原始快递公司如何识别成标准快递公司；
2. 是否因为重量达到大件阈值而切换到“大件”报价模板；
3. 报价表里对应业务员、模板、省份的首重费用和续重费用不同；
4. 德邦最终费用会四舍五入为整数。
```

## 1. 输入字段

每一行销售数据必须具备以下字段：

| 字段 | 用途 |
| :--- | :--- |
| `出库日期` | 用于后续客户每日明细拆分 |
| `业务员` | 用于匹配对应业务员的报价表 |
| `快递公司` | 用于解析标准快递公司 |
| `省` | 用于匹配报价表中的省份价格 |
| `重量` | 用于判断续重重量、是否大件、最终费用 |

报价表中每个 sheet 必须具备：

| 字段 | 用途 |
| :--- | :--- |
| `省份参照列` | 与销售表中的 `省` 匹配 |
| `首重费用` | 公式中的首重费用 |
| `续重费用` | 公式中的续重单价 |

报价表读取后，系统按下面这个三元组建立价格索引：

```text
业务员 + 计费模板 + 省
```

例如：

```text
小张 + 顺丰 + 广东
小张 + 顺丰_大件 + 广东
小陈 + 德邦 + 浙江
```

## 2. 快递公司识别逻辑

销售表里的 `快递公司` 可能不是标准名称，系统会先把它解析成标准快递公司。

当前默认标准快递公司主要来自报价表 sheet 名，例如：

```text
顺丰
申通
德邦
顺丰_大件
德邦_大件
```

解析顺序如下：

1. 如果销售表里的 `快递公司` 原值本身就是报价表中的标准 sheet 名，直接使用。
2. 如果原值命中精确映射，则转为对应标准名称。
3. 如果原值包含某个关键词，则按关键词映射为标准名称。
4. 如果匹配不到，当前行计算失败。
5. 如果同时匹配到多个标准名称，当前行计算失败。

当前默认精确映射：

| 原始快递公司 | 标准快递公司 |
| :--- | :--- |
| `顺丰速运新3` | `顺丰` |
| `顺丰速运开` | `顺丰` |
| `顺丰陈开专属` | `顺丰` |
| `申通E物流` | `申通` |
| `德邦快递盖子大360小泡货特惠_4` | `德邦` |
| `艾松仓库大件德邦` | `德邦` |

当前默认关键词映射：

| 关键词 | 标准快递公司 |
| :--- | :--- |
| `顺丰` | `顺丰` |
| `申通` | `申通` |
| `德邦` | `德邦` |

## 3. 计费模板选择逻辑

系统先得到标准快递公司，再结合重量决定使用哪个报价模板。

当前默认大件规则：

| 配置项 | 当前值 |
| :--- | :--- |
| 大件快递公司 | `顺丰`、`德邦` |
| 大件阈值 | `20kg` |
| 大件模板后缀 | `_大件` |

模板选择规则：

```text
如果 标准快递公司 属于大件快递公司，并且 重量 >= 20kg：
    计费模板 = 标准快递公司 + "_大件"
否则：
    计费模板 = 标准快递公司
```

也就是：

| 标准快递公司 | 重量 | 当前计费模板 |
| :--- | :--- | :--- |
| 顺丰 | `< 20kg` | `顺丰` |
| 顺丰 | `>= 20kg` | `顺丰_大件` |
| 德邦 | `< 20kg` | `德邦` |
| 德邦 | `>= 20kg` | `德邦_大件` |
| 申通 | 任意重量 | `申通` |

注意：`20kg` 本身会进入大件模板，因为代码判断条件是 `重量 >= 20`，不是 `重量 > 20`。

## 4. 续重重量计算逻辑

当前所有快递公司都使用相同的续重重量算法：

```text
如果 重量 <= 0：
    当前行失败
如果 重量 <= 1：
    续重重量 = 0
如果 重量 > 1：
    续重重量 = ceil(重量 - 1)
```

换句话说：

| 重量 | 续重重量 |
| :--- | :--- |
| 0 或负数 | 失败 |
| 0.1kg | 0 |
| 1kg | 0 |
| 1.01kg | 1 |
| 1.5kg | 1 |
| 2kg | 1 |
| 2.01kg | 2 |
| 20kg | 19 |
| 20.1kg | 20 |

这里的核心含义是：

```text
首重覆盖 1kg。
超过 1kg 的部分向上取整为续重重量。
```

## 5. 快递费用公式

当前所有快递公司先共用同一个基础费用公式：

```text
快递费用 = 首重费用 + 续重费用 * 续重重量
```

其中：

```text
首重费用 = 报价表中当前 业务员 + 计费模板 + 省 对应的首重费用
续重费用 = 报价表中当前 业务员 + 计费模板 + 省 对应的续重费用
续重重量 = ceil(重量 - 1)，但重量 <= 1 时为 0
```

默认保留 2 位小数。

德邦例外：标准快递公司为 `德邦` 时，不论当前使用的是 `德邦` 还是 `德邦_大件` 模板，最终快递费都会四舍五入为整数。

示例：

```text
业务员：小张
标准快递公司：顺丰
重量：2.3kg
省：广东
计费模板：顺丰
报价表：首重费用 10，续重费用 3

续重重量 = ceil(2.3 - 1) = 2
快递费用 = 10 + 3 * 2 = 16
```

大件示例：

```text
业务员：小张
标准快递公司：顺丰
重量：20kg
省：广东
计费模板：顺丰_大件
报价表：首重费用 30，续重费用 5

续重重量 = ceil(20 - 1) = 19
快递费用 = 30 + 5 * 19 = 125
```

## 6. 各快递公司的当前差异

### 顺丰

顺丰有普通模板和大件模板。

| 重量范围 | 使用模板 | 公式 |
| :--- | :--- | :--- |
| `< 20kg` | `顺丰` | `首重费用 + 续重费用 * 续重重量` |
| `>= 20kg` | `顺丰_大件` | `首重费用 + 续重费用 * 续重重量` |

### 德邦

德邦有普通模板和大件模板。

| 重量范围 | 使用模板 | 公式 |
| :--- | :--- | :--- |
| `< 20kg` | `德邦` | `首重费用 + 续重费用 * 续重重量`，最终费用四舍五入为整数 |
| `>= 20kg` | `德邦_大件` | `首重费用 + 续重费用 * 续重重量`，最终费用四舍五入为整数 |

### 申通

申通目前没有默认大件切换规则。

| 重量范围 | 使用模板 | 公式 |
| :--- | :--- | :--- |
| 任意正重量 | `申通` | `首重费用 + 续重费用 * 续重重量` |

## 7. 当前容易引发业务确认的点

下面这些点不是代码错误，而是后续可以重点确认是否符合真实业务规则：

1. **所有公司都按 1kg 首重计算**  
   当前没有针对不同快递公司配置首重重量，例如 0.5kg 首重、3kg 首重。

2. **所有续重都按向上取整计算**  
   例如 1.01kg 会按 1kg 续重收取，2.01kg 会按 2kg 续重收取。

3. **顺丰、德邦 20kg 起就进入大件模板**  
   如果业务实际是 `> 20kg` 才算大件，当前逻辑需要调整。

4. **德邦最终费用会取整，顺丰和申通不会**  
   当前只有德邦在公式结果出来后额外做整数四舍五入。

5. **大件模板仍然套用同一套首重 + 续重公式**  
   当前没有“大件按区间价”“大件按整票价”“大件最低收费”等特殊算法。

6. **申通没有大件模板切换**  
   如果申通也存在大件或超重规则，需要把申通加入大件快递公司，或者设计更细的规则。

7. **报价表只支持省级匹配**  
   当前价格索引是 `业务员 + 计费模板 + 省`，没有城市、区县、重量区间或目的地分区。

8. **重量必须大于 0**  
   空、非数字、0、负数都会导致该行计算失败。

9. **快递公司识别依赖默认映射和关键词**  
   如果销售表出现新快递公司名称，可能需要在规则配置里补充映射。

## 8. 对后续优化的建议方向

如果要优化计费逻辑，可以考虑按复杂度分三档：

| 方向 | 适合解决的问题 | 改动复杂度 |
| :--- | :--- | :--- |
| 补充快递公司映射 | 销售表里快递公司名称越来越多，识别失败 | 低 |
| 调整大件规则 | 某些公司阈值不同、是否含 20kg 规则不同 | 中 |
| 引入分公司/分模板计费规则 | 不同快递公司有不同首重重量、续重单位、最低收费、区间价 | 高 |

当前最值得优先确认的是：

```text
1. 顺丰和德邦是否真的是 20kg 含 20kg 进入大件模板？
2. 大件是否仍然按 1kg 首重 + 向上取整续重计算？
3. 申通是否永远不走大件模板？
4. 是否存在不同快递公司首重重量不同的情况？
5. 除德邦外，是否还有其他快递公司也需要最终费用四舍五入为整数？
6. 是否存在最低收费、封顶价、阶梯价或按重量区间一口价？
```
