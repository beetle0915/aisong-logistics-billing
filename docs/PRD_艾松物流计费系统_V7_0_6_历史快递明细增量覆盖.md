# 艾松物流计费系统 V7.0.6 历史快递明细增量覆盖 PRD

## 背景

V7.0.5 已在客户历史汇总表中加入 `历史汇总` 和 `收款记录`，支持客户查看每日快递消费、收款、累计收款和余额。当前客户仍缺少一张长期累计的逐条快递记录表，只能打开每日明细文件查看单日详情。

V7.0.6 新增客户级 `快递明细` sheet，用于累计客户历史所有快递记录。

## 目标

1. 客户历史汇总工作簿新增 `快递明细` sheet。
2. `快递明细` 可见列与每日明细文件中的 `快递明细` sheet 保持一致。
3. 每次刷新客户历史汇总时，扫描客户目录下所有每日明细文件，将逐条快递记录写入历史 `快递明细`。
4. 使用 `出库单号 + 出库日期` 作为历史记录 Key。
5. 同 Key 记录采用后到覆盖先到，不重复追加。
6. 隐藏系统列记录 Key、首次导入时间、最后更新时间、来源明细文件和来源行号。
7. 保留 V7.0.5 的 `历史汇总` 和 `收款记录` 行为。
8. 版本号升级为 `V7.0.6`。

## Workbook 结构

客户历史汇总工作簿 sheet 顺序：

```text
历史汇总
快递明细
收款记录
```

文件名继续使用：

```text
业务员名称_客户快递费历史汇总.xlsx
```

## 快递明细 Sheet

可见列与客户每日明细文件中的 `快递明细` sheet 一致，不额外改变客户可见格式。

系统隐藏列追加在可见列右侧：

| 字段 | 说明 |
| :--- | :--- |
| 历史记录Key | `出库单号 + 出库日期` 标准化后的唯一 Key |
| 首次导入时间 | 记录第一次写入历史明细的时间 |
| 最后更新时间 | 记录最近一次写入或覆盖的时间 |
| 来源明细文件 | 本次数据来自哪个每日明细文件 |
| 来源行号 | 本次数据来自每日明细 sheet 第几行 |

隐藏列默认隐藏，客户正常查看时只看到每日明细一致的字段。

## 覆盖规则

历史记录 Key：

```text
历史记录Key = 出库单号 + "|" + 标准化后的出库日期时间
```

示例：

```text
575885|2026-04-07 18:31:58
```

处理规则：

```text
如果 Key 不存在：
    追加新行

如果 Key 已存在：
    用本次记录覆盖旧行的可见字段
    保留首次导入时间
    更新最后更新时间、来源明细文件、来源行号
```

如果某行缺少 `出库单号` 或 `出库日期`，该行无法安全覆盖，系统跳过该行并记录警告。

## 非目标

1. 本版本不改变快递费计算规则。
2. 本版本不改变客户每日明细文件结构。
3. 本版本不改 `历史汇总` 的费用/收款/余额公式。
4. 本版本不新增数据库，仍以 Excel 工作簿作为客户账本。

## 验收标准

1. 新生成的客户历史汇总文件包含 `历史汇总`、`快递明细`、`收款记录` 三个 sheet。
2. `快递明细` 可见表头与每日明细一致。
3. `快递明细` 右侧存在隐藏系统列。
4. 同一 `出库单号 + 出库日期` 重复出现时，不新增重复行，而是覆盖旧行。
5. 新 Key 记录追加到历史快递明细中。
6. 覆盖时保留首次导入时间，并更新最后更新时间。
7. `收款记录` 刷新后仍保留人工录入内容。
8. 单元测试覆盖新增 sheet、隐藏列、追加和覆盖行为。
