# 艾松运费管家 V8.5.6 报价预览分栏和打开价格表 PRD

## 背景

V8.5.5 已经让报价预览表格左右两组列等宽、居中，并增加了中间实线。继续查看较长报价表时，左右两列如果按相邻两条记录并排，浏览顺序不够自然。用户希望前一半省份展示在左边，后一半省份展示在右边。同时，查看报价时需要能直接打开当前客户的原始价格表。

## 目标

1. 版本升级为 `V8.5.6`。
2. `报价预览 -> 当前客户快递价格信息` 的分栏策略改为：
   - 前一半省份记录展示在左侧三列。
   - 后一半省份记录展示在右侧三列。
   - 如果总行数为奇数，左侧多一行，右侧末行留空。
3. 在 `当前客户快递价格信息` 区域新增 `打开快递价格表` 按钮。
4. 点击按钮后打开当前搜索到的客户报价 Excel 文件。

## 非目标

- 不修改报价表读取规则。
- 不修改报价预览的 6 列结构。
- 不修改计费、拆分和客户历史汇总逻辑。

## 验收标准

1. `APP_VERSION` 为 `8.5.6`，输出后缀为 `v8_5_6`。
2. 4 条省份报价展示为第 1/3 条一行、第 2/4 条一行。
3. 1 条或奇数条报价时，右侧缺失位置留空。
4. 搜索客户报价后，系统记录当前客户报价文件路径。
5. `打开快递价格表` 按钮可打开当前客户报价文件；未搜索时提示先选择业务员并搜索。
