# 艾松运费管家 V8.5.1 运行日志阶段摘要优化 PRD

## 背景

V8.5 已经让运行日志支持实时刷新，用户点击 `开始计算` 后能看到任务仍在执行。但实际日志仍偏技术流水账，例如报价目录路径、保存文件、写入汇总表等内部动作较多。客户真正需要的是看懂当前跑到哪一步、已经处理多少、哪些阶段完成了。

V8.5.1 的目标不是增加更多日志，而是把已有实时日志整理成客户可读的 `阶段摘要 + 关键里程碑`。

## 目标

1. 版本号升级为 `V8.5.1`。
2. 实时日志保留当前 GUI 刷新机制，不改变后台任务队列。
3. 日志按阶段展示：
   - 阶段 1/5：准备数据
   - 阶段 2/5：计算快递费
   - 阶段 3/5：生成客户每日明细
   - 阶段 4/5：刷新客户历史汇总
   - 阶段 5/5：完成
4. 阶段内只显示关键里程碑和少量真实数量进度。
5. 实时日志不再输出报价目录、输出目录、拆分目录等完整路径。
6. 具体生成文件仍在 `结果` 页面查看。

## 日志文案规范

实时日志使用三类客户可读文案：

```text
阶段 1/5：准备数据，共 3 个销售表
阶段 2/5：计算快递费
进度：正在处理销售表 1/3：销售出库单.xlsx
里程碑：报价读取完成，共 180 条报价
进度：快递费计算已处理 200/1200 行，成功 198 行，异常 2 行
阶段 3/5：生成客户每日明细
里程碑：客户每日明细生成完成，共 86 份，异常 0 行
阶段 4/5：刷新客户历史汇总
进度：客户历史汇总已刷新 12/35 位客户
阶段 5/5：完成，销售表 3/3，成功 3560 行，异常 4 行；生成文件请到「结果」页查看
```

规则：

- 阶段开始使用 `阶段 x/5：...`。
- 阶段完成使用 `里程碑：...完成`。
- 数量变化使用 `进度：...已处理/已生成/已刷新`。
- 运行中把需要人工处理的行称为 `异常`，最终错误原因仍在 `需要处理的问题` 中展示。
- 不在实时日志反复显示完整文件路径。
- 不展示保存文件、写入 sheet 等内部动作。

## 验收标准

1. 点击 `开始计算` 后仍自动进入 `费用计算 -> 运行`。
2. 任务未结束时，运行日志已经能看到阶段摘要和真实数量进度。
3. 日志包含阶段 1/5 到阶段 5/5。
4. 日志包含报价读取完成、快递费计算进度、客户每日明细完成、客户历史汇总刷新进度。
5. 实时日志不包含 `->` 或本地输出目录路径。
6. 任务完成后，结果文件仍在 `结果` 页面展示。
