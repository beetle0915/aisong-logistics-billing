# 艾松物流计费系统 V7.0.8 生成选项状态标识优化 PRD

## 背景

桌面 GUI 中 `生成客户每日明细`、`生成客户历史汇总`、`刷新全部客户历史汇总` 使用系统主题复选框。当前主题在选中状态下可能显示为 `❌`，用户容易误解为该功能被关闭或异常。

V7.0.8 优化这几个生成选项的状态表达，让选中和未选中更直观。

## 目标

1. 选中状态显示 `✅`。
2. 未选中状态显示 `□`。
3. 不再出现 `❌` 作为生成选项状态标识。
4. 保留原有配置含义：
   - `生成客户每日明细` 控制是否生成客户每日明细。
   - `生成客户历史汇总` 控制是否生成客户历史汇总。
   - `刷新全部客户历史汇总` 控制是否刷新全部客户历史汇总。
5. `生成客户每日明细` 关闭时，继续自动关闭 `刷新全部客户历史汇总`。

## 实现设计

GUI 保留 `ttk.Checkbutton` 的开关行为，但隐藏系统原生 indicator，使用按钮文字前缀表达状态：

```text
✅ 生成客户每日明细
□ 生成客户每日明细
```

这样可以避免不同 macOS/Tk 主题把选中状态渲染成不符合业务语义的符号。

## 验收标准

1. 选中 `生成客户每日明细` 时，文字显示 `✅ 生成客户每日明细`。
2. 未选中 `生成客户每日明细` 时，文字显示 `□ 生成客户每日明细`。
3. `生成客户历史汇总` 和 `刷新全部客户历史汇总` 使用同样规则。
4. 任何选项状态文本都不包含 `❌`。
5. 配置保存、任务运行参数构建逻辑不变。
6. 版本号升级为 `V7.0.8`。
