# 艾松运费管家 V8.2.1 费用计算三步流程修正 PRD

## 背景

V8.2 已经把目录配置、快递公司映射和大件规则迁移到 `系统设置`，但 `费用计算` 页仍保留了目录配置编辑入口。同时顶部 `配置 / 运行 / 结果` 只是静态标签，用户会误以为 `运行` 和 `结果` 可点击。

V8.2.1 参考 `head` 设计包，将费用计算页修正为真实三步流程，并收敛重复配置入口。

## 目标

1. 版本号升级为 `V8.2.1`。
2. `费用计算` 页提供可点击的 `配置 / 运行 / 结果` 三个步骤。
3. `配置` 步只处理本次任务输入和生成选项，不再编辑系统目录。
4. 系统级目录继续统一在 `系统设置` 的 `目录配置` 中维护。
5. 点击 `开始计算` 后自动进入 `运行` 步。
6. 运行完成后自动进入 `结果` 步。
7. 不改变计费、拆分、客户历史汇总和 Excel 输出逻辑。

## 页面结构

### 费用计算 - 配置

- 销售出库单：支持多选销售表。
- 当前系统设置：只读显示报价表目录、总结果目录、客户明细目录。
- 生成选项：
  - 生成客户每日明细
  - 生成客户历史汇总
  - 刷新全部客户历史汇总
- 操作：
  - 去系统设置
  - 开始计算

### 费用计算 - 运行

- 当前状态：就绪、运行中、完成、完成有错误、失败。
- 统计卡片：销售表、成功、失败、生成文件。
- 运行日志：继续展示详细处理日志和异常建议。

### 费用计算 - 结果

- 统计卡片：销售表、成功、失败、生成文件。
- 生成结果表：类型、文件名、路径。
- 操作：
  - 打开选中文件
  - 打开所在目录
  - 打开输出目录
  - 重新运行

## 交互规则

1. 用户可点击步骤条在 `配置 / 运行 / 结果` 之间切换。
2. 如果任务正在运行，再次点击开始计算时切回 `运行` 步并提示等待。
3. 如果配置校验失败，停留在当前步骤，提示用户修正。
4. 任务成功或有业务错误时，都进入 `结果` 步，方便查看生成文件和统计。
5. 未捕获异常导致任务失败时，停留或切回 `运行` 步，优先让用户查看错误日志。

## 验收标准

1. 主界面显示版本号 `V8.2.1`。
2. 费用计算页的 `配置 / 运行 / 结果` 均可点击切换。
3. 费用计算页不再直接编辑报价表目录、总结果目录和客户明细目录。
4. 配置页显示系统目录摘要，并提供进入系统设置的入口。
5. 点击开始计算后自动切到运行页。
6. 运行完成后自动切到结果页。
7. 现有测试通过。
8. `python -m compileall -q app tests` 通过。
9. macOS 打包自检通过。
10. `git diff --check` 通过。
