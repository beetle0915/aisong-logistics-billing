# 艾松运费管家 V8.2 系统设置页面 PRD

## 背景

V8.1 已经接入 head 风格的费用计算主流程，并在左侧导航中预留 `系统设置`。当前规则配置仍通过独立弹窗进入，目录配置仍分散在费用计算页。为了让软件更接近 head 原型的信息架构，V8.2 将 `系统设置` 从占位导航升级为可用页面。

## 目标

1. 版本号升级为 `V8.2`。
2. 左侧导航中 `系统设置` 可点击进入真实页面。
3. 系统设置页面集中维护：
   - 目录配置
   - 精确映射
   - 关键词映射
   - 大件规则
4. 保持原有配置文件结构不变，避免影响旧用户配置。
5. 不改变任何计费规则和 Excel 输出逻辑。

## 范围

### 本次包含

- 启用左侧导航中的 `系统设置`。
- 保留 `费用计算` 页面。
- `账户余额`、`报价预览`、`客户档案` 继续作为后续占位。
- 系统设置页面提供目录配置入口：
  - 报价表目录
  - 总结果目录
  - 客户明细目录
- 系统设置页面提供规则配置入口：
  - 精确映射
  - 关键词映射
  - 大件快递
  - 重量阈值
  - 模板后缀
- 保存系统设置时复用现有规则校验逻辑。
- 侧边栏原 `规则配置` 按钮改为跳转到 `系统设置` 页面。

### 本次不包含

- 不新增账户余额页面。
- 不新增报价预览页面。
- 不新增客户档案页面。
- 不改变客户历史汇总、收款记录和余额公式。
- 不改变报价表或销售表格式。
- 不改变配置 JSON 字段结构。

## 交互说明

1. 点击左侧 `系统设置`，主内容区切换到系统设置页面。
2. 点击左侧 `费用计算`，主内容区切回费用计算页面。
3. 系统设置页面中，目录配置仍使用系统文件夹选择窗口。
4. 修改映射或大件规则后，点击 `保存系统设置`。
5. 如果规则格式错误，弹窗提示错误原因，不保存无效配置。
6. 点击 `恢复默认规则` 会恢复默认快递映射和大件规则，并保存配置。

## 验收标准

1. 主界面显示版本号 `V8.2`。
2. 左侧 `费用计算` 和 `系统设置` 都可用。
3. 系统设置页面包含 `目录配置`、`精确映射`、`关键词映射`、`大件规则` 四个分区。
4. 系统设置保存后，后续费用计算使用新规则。
5. 无效规则会阻止保存并提示原因。
6. 现有单元测试通过。
7. `python -m compileall -q app tests` 通过。
8. macOS 打包自检通过。
9. `git diff --check` 通过。
