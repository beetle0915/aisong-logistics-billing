# 艾松运费管家 V8.3.1 账户余额刷新按钮优化 PRD

## 背景

V8.3 已经上线 `账户余额` 页面，可以从客户历史汇总表读取累计消费、累计收款、当前余额和欠款客户。实际使用时，统计卡片下方又出现一行 `搜索客户`、`刷新数据`、`打开客户目录`，与底部操作区重复，页面层级不够清晰。

## 需求

1. 版本号升级为 `V8.3.1`。
2. 移除 `账户余额` 页面统计卡片下方的整行操作区：
   - `搜索客户`
   - 顶部 `刷新数据`
   - 顶部 `打开客户目录`
3. 在底部操作区新增 `刷新数据` 按钮，位置在 `打开客户目录` 左边。
4. 底部 `刷新数据` 按钮使用和 `开始计算` 一致的主按钮样式。
5. 移除隐藏搜索过滤逻辑，避免搜索框不显示时仍然按旧状态过滤客户列表。

## 交互设计

`账户余额` 页面结构：

```text
统计卡片

客户余额表
  表格内容
  状态文本                              刷新数据  打开客户目录  打开历史汇总表
```

## 验收标准

1. `账户余额` 页面统计卡片下方不再显示搜索客户、刷新数据、打开客户目录这一行。
2. 客户余额表底部显示 `刷新数据`、`打开客户目录`、`打开历史汇总表`。
3. `刷新数据` 位于 `打开客户目录` 左侧，并使用主按钮样式。
4. 刷新余额表时显示全部客户，不再依赖已移除的搜索框状态。
5. 主界面和打包元数据显示 `V8.3.1`。
