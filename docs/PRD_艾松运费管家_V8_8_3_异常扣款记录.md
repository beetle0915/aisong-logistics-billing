# 艾松运费管家 V8.8.3 异常扣款记录 PRD

## 背景

V8.8.2 已完成客户历史汇总中 `快递明细` 的已发货状态去重 Key。当前客户历史汇总表已经包含 `历史汇总`、`快递明细`、`收款记录` 三个 sheet，并通过 `收款记录` 的公式计算每日收款、累计收款和当前余额。

实际对账时，客户除了正常快递消费和收款，还会发生额外扣款，例如异常调整、赔付扣减或其他手工扣款。现有表格没有独立位置登记这类扣款，用户只能把扣款混进收款或备注里，容易影响余额理解。

V8.8.3 新增 `异常扣款记录` sheet，并在 `历史汇总` 中同步每日和累计异常扣款，让账户余额同时体现正常消费、收款和额外扣款。

## 目标

1. 客户历史汇总工作簿新增 `异常扣款记录` sheet。
2. `异常扣款记录` 使用固定表头：`扣款时间`、`额度`、`备注`。
3. `额度` 由用户填写正数，表示本次扣款金额。
4. `历史汇总` 新增 `今日异常扣款`、`累计异常扣款` 两列。
5. 新增两列通过 Excel 公式从 `异常扣款记录` 按日期同步。
6. `当前余额` 公式调整为：`累计收款 - 累计快递费用 - 累计异常扣款`。
7. 刷新客户历史汇总时保留已有 `异常扣款记录` 的人工录入内容。
8. 账户余额页读取客户历史汇总时，同步扣减 `异常扣款记录` 的额度。
9. 版本号升级为 `8.8.3`，输出后缀为 `v8_8_3`。

## Sheet 设计

### 历史汇总

字段顺序：

| 字段 | 说明 |
| :--- | :--- |
| 日期 | 每日明细对应出库日期 |
| 单数 | 当日快递单数 |
| 总重量 | 当日总重量 |
| 今日快递总消费 | 当日快递费 |
| 累计快递费用 | 截至当日累计快递费 |
| 今日收款 | 从 `收款记录` 按支付时间匹配当日收款金额 |
| 累计收款 | 从 `收款记录` 统计截至当日累计收款 |
| 今日异常扣款 | 从 `异常扣款记录` 按扣款时间匹配当日扣款金额 |
| 累计异常扣款 | 从 `异常扣款记录` 统计截至当日累计扣款 |
| 当前余额 | `累计收款 - 累计快递费用 - 累计异常扣款` |
| 顺丰单数 | 当日顺丰单数 |
| 申通单数 | 当日申通单数 |
| 德邦单数 | 当日德邦单数 |
| 大件单数 | 当日大件单数 |

公式规则：

```text
今日异常扣款 = SUMIFS('异常扣款记录'!$B:$B, '异常扣款记录'!$A:$A, ">=" & 当前行日期, '异常扣款记录'!$A:$A, "<" & 当前行日期 + 1)
累计异常扣款 = SUMIFS('异常扣款记录'!$B:$B, '异常扣款记录'!$A:$A, "<" & 当前行日期 + 1, '异常扣款记录'!$A:$A, "<>")
当前余额 = 累计收款 - 累计快递费用 - 累计异常扣款
```

以第 2 行为例：

```text
H2 = SUMIFS('异常扣款记录'!$B:$B,'异常扣款记录'!$A:$A,">="&A2,'异常扣款记录'!$A:$A,"<"&A2+1)
I2 = SUMIFS('异常扣款记录'!$B:$B,'异常扣款记录'!$A:$A,"<"&A2+1,'异常扣款记录'!$A:$A,"<>")
J2 = G2-E2-I2
```

### 异常扣款记录

字段顺序：

| 字段 | 说明 |
| :--- | :--- |
| 扣款时间 | 扣款发生日期，用于匹配 `历史汇总` 日期 |
| 额度 | 本次扣款金额，用户填写正数 |
| 备注 | 扣款原因或说明 |

格式规则：

- `扣款时间` 使用日期格式 `yyyy-mm-dd`。
- `额度` 使用金额格式 `0.00`。
- 预留不少于 20 行基础格式和边框，方便用户直接录入。
- `异常扣款记录` 是人工维护 sheet。系统刷新历史汇总时只补齐表头和格式，不覆盖已有扣款数据。

## 工作簿结构

客户历史汇总文件仍使用：

```text
客户名称_客户快递费历史汇总.xlsx
```

sheet 顺序：

```text
历史汇总
快递明细
收款记录
异常扣款记录
```

## 兼容规则

1. 刷新新版历史汇总时，如果旧文件存在 `异常扣款记录`，保留已有人工录入内容，并套用统一表头和基础格式。
2. 如果旧文件没有 `异常扣款记录`，自动创建空 sheet 并写入表头和基础格式。
3. `收款记录` 的保留逻辑不变。
4. `快递明细` 的增量覆盖逻辑不变。
5. `历史汇总` 每次重新生成公式，旧文件刷新后会自动获得新增扣款列。
6. Excel 打开文件时自动重算公式，延续现有 `收款记录` 的计算方式。
7. 账户余额页不依赖 Excel 公式缓存，读取 `异常扣款记录` 的 `额度` 列并按正数扣减；旧文件缺少该 sheet 时按 0 处理。

## 范围外

1. 不在 GUI 中新增异常扣款录入页面。
2. 不自动识别销售明细中的异常扣款。
3. 不把扣款写入 `收款记录`，避免收入和扣款混用。
4. 不改变 `快递明细` 的历史记录 Key 规则。
5. 不在账户余额页新增单独的异常扣款列；本版本只让现有余额数值扣减异常扣款。

## 验收标准

1. `APP_VERSION` 为 `8.8.3`，输出后缀为 `v8_8_3`。
2. 新生成的客户历史汇总文件包含 `历史汇总`、`快递明细`、`收款记录`、`异常扣款记录` 四个 sheet，且顺序正确。
3. `异常扣款记录` 表头为 `扣款时间`、`额度`、`备注`。
4. `历史汇总` 表头包含 `今日异常扣款`、`累计异常扣款`，并位于 `累计收款` 和 `当前余额` 之间。
5. `历史汇总` 的异常扣款列为 `SUMIFS` 公式，引用 `异常扣款记录` 的 `扣款时间` 和 `额度`。
6. `当前余额` 公式扣减 `累计异常扣款`。
7. 已存在 `异常扣款记录` 数据时，刷新客户历史汇总后原有手工扣款记录仍保留。
8. 账户余额页读取新版客户历史汇总时，当前余额扣减 `异常扣款记录` 中的正数额度；旧文件缺少该 sheet 时仍正常读取。
9. 客户历史汇总、账户余额和品牌版本相关单元测试通过。
