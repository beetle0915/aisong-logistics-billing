# 艾松运费管家使用说明

适用版本：`V7.0.10`

这份说明写给第一次使用软件的同事或客户。你只需要准备好销售出库单和快递报价表，按步骤选择文件和目录，软件就会自动计算快递费，并生成方便查看和对账的 Excel 文件。

## 1. 这个软件是做什么的

`艾松运费管家` 主要用来处理每天的快递费用。

它可以帮你完成这些事情：

- 根据销售出库单自动计算每一单快递费。
- 一次选择多个销售出库单，批量处理。
- 按业务员或客户拆分每日快递明细。
- 给每个客户生成一份长期历史汇总表。
- 在客户历史汇总表里查看每日消费、累计消费、收款记录和当前余额。
- 遇到表格缺列、重量异常、报价找不到等问题时，在运行日志里提示原因和处理建议。

简单理解：每天拿销售出库单跑一次，软件会帮你算出总费用，并整理好客户对账用的表。

## 2. 使用前需要准备什么

### 2.1 销售出库单

销售出库单必须是 Excel 文件，格式通常是 `.xlsx`。

表里至少要有这些列：

| 列名 | 用途 |
| --- | --- |
| `出库日期` | 用来判断这一单是哪一天发出的 |
| `业务员` | 用来匹配对应业务员的报价表，也会作为客户拆分依据 |
| `快递公司` | 用来判断使用哪个快递报价 |
| `省` | 用来匹配对应省份的快递价格 |
| `重量` | 用来计算首重、续重和总快递费 |

强烈建议保留这一列：

| 列名 | 用途 |
| --- | --- |
| `出库单号` | 用来判断历史明细是否重复，避免同一单被重复追加 |

如果没有 `出库单号`，总费用仍可能可以计算，但客户历史 `快递明细` 的去重能力会受到影响。

### 2.2 快递报价表

每个业务员需要有自己的快递报价 Excel。

报价表文件名建议包含业务员名称，例如：

```text
张三-快递报价.xlsx
李四-快递报价.xlsx
```

报价表里的 sheet 名要和快递模板对应，例如：

```text
顺丰
顺丰_大件
申通
德邦
德邦_大件
```

每个报价 sheet 至少需要这些列：

| 列名 | 用途 |
| --- | --- |
| `省份参照列` | 对应销售出库单里的省份 |
| `首重费用` | 首重价格 |
| `续重费用` | 超过首重后的续重价格 |

注意：如果销售表里有顺丰或德邦 20kg 以上的大件，报价表里需要有 `顺丰_大件` 或 `德邦_大件` 这类 sheet。

## 3. 推荐目录怎么放

建议在电脑上固定几个目录，后续每天都放到同样的位置，减少选错文件的机会。

示例：

```text
express/
  原始数据表/
  快递报价表/
  输出结果/
  客户每日快递费明细/
```

每个目录的作用：

| 目录 | 放什么 |
| --- | --- |
| `原始数据表` | 每天要处理的销售出库单 |
| `快递报价表` | 各业务员的报价表 |
| `输出结果` | 软件生成的总结果表 |
| `客户每日快递费明细` | 按客户拆分出来的每日明细和历史汇总 |

## 4. 第一次使用怎么操作

打开 `艾松运费管家` 后，按下面顺序操作。

### 第一步：选择销售出库单

点击 `销售出库单` 后面的 `多选`。

可以选择一个 Excel，也可以一次选择多个 Excel。

适合这些情况：

- 今天只有一张销售出库单，就选一张。
- 今天分了多个销售表，就一次多选。
- 要补跑之前几天的数据，也可以把对应文件一起选上。

### 第二步：选择报价表目录

点击 `报价表目录` 后面的 `选择`。

这里要选的是“放报价表的文件夹”，不是某一个报价表文件。

正确示例：

```text
/Users/xxx/Desktop/express/快递报价表
```

错误示例：

```text
/Users/xxx/Desktop/express/快递报价表/张三-快递报价.xlsx
```

### 第三步：选择总结果目录

点击 `总结果目录` 后面的 `选择`。

总结果表会生成到这个目录里。这个表是在原销售出库单基础上增加快递费用等计算结果。

### 第四步：选择客户明细目录

点击 `客户明细目录` 后面的 `选择`。

客户每日明细和客户历史汇总表都会放在这个目录下。

### 第五步：确认生成选项

界面上有三个选项：

| 选项 | 建议 | 说明 |
| --- | --- | --- |
| `生成客户每日明细` | 建议勾选 | 按客户生成当天明细 |
| `生成客户历史汇总` | 建议勾选 | 自动维护每个客户的历史账本 |
| `刷新全部客户历史汇总` | 按需勾选 | 需要重新整理所有客户历史汇总时使用 |

选中时会显示 `✅`，未选中时会显示 `□`。

日常使用一般勾选前两个就可以。

### 第六步：点击开始运行

点击 `开始运行`。

运行时请不要关闭软件，等待状态变成完成。

运行结束后，可以在右侧 `生成结果` 里看到生成的文件。你可以：

- 双击文件打开。
- 点击 `打开选中文件`。
- 点击 `打开所在目录`。
- 点击 `打开输出目录`。
- 点击 `打开客户目录`。

## 5. 生成的文件怎么看

### 5.1 总结果表

总结果表会生成在 `总结果目录`。

文件名类似：

```text
【4.7】销售出库单_快递费计算结果_v7_0_10.xlsx
```

它会在原销售出库单基础上增加这些列：

| 列名 | 说明 |
| --- | --- |
| `快递费用` | 软件计算出的最终快递费 |
| `首重费用` | 报价表匹配到的首重费用 |
| `续重费用` | 报价表匹配到的续重费用 |
| `续重重量` | 超出首重后参与续重计算的重量 |
| `快递公司（标准版）` | 软件识别后的快递公司名称 |

这个文件适合内部检查整体计算结果。

### 5.2 客户每日明细

客户每日明细会放在 `客户明细目录` 下，并按客户分文件夹。

示例：

```text
客户每日快递费明细/
  张三/
    2026-04-07_张三_快递费明细.xlsx
```

这个文件适合查看某个客户某一天的所有快递记录。

### 5.3 客户历史汇总表

每个客户会有一份历史汇总表。

示例：

```text
张三_客户快递费历史汇总.xlsx
```

这个表最适合发给客户或用于长期对账。

里面有三个 sheet：

| Sheet | 看什么 |
| --- | --- |
| `历史汇总` | 每天合计消费、累计消费、今日收款、累计收款、当前余额 |
| `快递明细` | 客户历史所有逐条快递记录 |
| `收款记录` | 手工登记客户付款或充值记录 |

## 6. 收款记录和余额怎么用

客户历史汇总表里有一个 `收款记录` sheet。

表头是：

```text
支付时间
支付方式
收款人
已付金额
收款时间
```

客户付款后，在这里新增一行即可。

示例：

| 支付时间 | 支付方式 | 收款人 | 已付金额 | 收款时间 |
| --- | --- | --- | --- | --- |
| 2026-04-02 | 微信 | 张三 | 5000 | 2026-04-02 10:30 |
| 2026-04-02 | 银行卡 | 张三 | 5000 | 2026-04-02 15:20 |
| 2026-04-03 | 支付宝 | 张三 | 3000 | 2026-04-03 09:10 |

填写重点：

- `支付时间` 一定要填成 Excel 能识别的日期，建议使用 `2026-04-02` 这种格式。
- `已付金额` 只填数字，不要写 `元`。
- `支付方式` 可以写微信、支付宝、银行卡、现金等。
- `收款人` 和 `收款时间` 方便内部追溯，建议填写。

`历史汇总` sheet 会自动计算：

| 字段 | 含义 |
| --- | --- |
| `今日收款` | 这个日期当天收到的钱 |
| `累计收款` | 截止这个日期为止累计收到的钱 |
| `当前余额` | 累计收款减去累计快递费用 |

注意：如果你改了 `收款记录`，Excel 有时需要重新打开文件，或者按一下保存，公式结果才会刷新显示。

## 7. 历史快递明细如何避免重复

客户历史汇总表里的 `快递明细` 会长期累积客户的逐条快递记录。

软件用下面两个字段判断是不是同一条记录：

```text
出库单号 + 出库日期
```

规则是：

- 第一次出现的新记录，会追加到历史明细里。
- 如果同一个 `出库单号 + 出库日期` 后面又出现，软件会用后来的记录覆盖之前的记录。
- 这样可以减少重复导入，也方便修正之前导入过的数据。

所以请尽量保证销售出库单里的 `出库单号` 和 `出库日期` 准确。

## 8. 规则配置什么时候需要改

大多数时候不需要改。

只有遇到下面情况，才需要打开 `规则配置`：

- 销售表里的快递名称比较特殊，软件识别不到。
- 报价表里的 sheet 名和销售表里的快递名称不一致。
- 新增了快递公司。
- 顺丰、德邦大件规则需要调整。

规则配置里最重要的是“快递公司映射”。

示例：

```text
顺丰速运新3=顺丰
申通E物流=申通
德邦快递盖子大360小泡货特惠_4=德邦
```

等号左边是销售表里的原始名称，等号右边是报价表里的 sheet 名。

建议：不要随意删除已有规则。如果不确定怎么改，先备份当前配置或联系维护人员。

## 9. 常见问题怎么处理

### 9.1 提示报价目录没有 .xlsx 报价文件

可能原因：

- 选错目录了。
- 报价表不在这个文件夹里。
- 报价表不是 `.xlsx` 格式。
- macOS 没有授权软件访问这个目录。

处理办法：

- 重新选择“放报价表的文件夹”。
- 确认文件夹里确实有 `张三-快递报价.xlsx` 这种文件。
- 如果是 macOS，可以重新选择一次目录，让系统重新授权。

### 9.2 提示销售表缺必要列

说明销售出库单缺少软件需要的表头。

处理办法：

- 看运行日志里提示缺少哪些列。
- 打开销售出库单，把缺少的列补上。
- 表头名称尽量保持一致，例如 `出库日期` 不要写成 `日期`。

### 9.3 提示重量不是数字

说明某一行的 `重量` 不是正常数字。

常见错误：

```text
空白
未知
约5kg
5公斤
```

正确写法：

```text
5
5.2
20
```

处理办法：

- 根据运行日志里的行号找到对应行。
- 把重量改成纯数字。
- 不要带 `kg`、`公斤` 等文字。

### 9.4 提示找不到报价

可能原因：

- 业务员没有对应报价表。
- 报价表里缺少对应快递 sheet。
- 报价表里没有对应省份。
- 销售表里的快递公司名称没有映射成功。

处理办法：

- 检查业务员名称是否和报价表文件名能对应上。
- 检查报价表里是否有对应 sheet，例如 `顺丰`、`德邦`。
- 检查省份名称是否和报价表一致。
- 必要时打开 `规则配置`，补充快递公司映射。

### 9.5 提示缺少顺丰_大件或德邦_大件

说明有顺丰或德邦 20kg 以上的大件，但报价表里没有大件报价 sheet。

处理办法：

- 打开对应业务员的报价表。
- 新增 `顺丰_大件` 或 `德邦_大件` sheet。
- 填好省份、首重费用、续重费用。

## 10. 日常使用注意事项

为了减少出错，建议按下面习惯使用：

- 每天处理前，先确认销售出库单表头完整。
- 重量列只填数字。
- 省份名称尽量统一，例如不要一会儿写 `广东`，一会儿写 `广东省`。
- 业务员名称要和报价表文件名保持一致。
- 报价表 sheet 名不要随意改。
- 客户历史汇总表可以打开查看，但不要随意删除隐藏列或修改系统生成的公式。
- `收款记录` 可以手工填写，但不要改表头。
- 重新跑旧数据前，最好先备份客户历史汇总表。
- 如果运行失败，先看左侧 `运行日志`，日志通常会说明是哪一行、哪个文件、哪个报价表有问题。
- 发给维护人员排查时，尽量同时提供销售出库单、报价表和完整运行日志。

## 11. 推荐的日常流程

每天使用可以按这个流程来：

1. 把当天销售出库单放进 `原始数据表`。
2. 确认 `快递报价表` 目录里的报价表是最新的。
3. 打开 `艾松运费管家`。
4. 多选当天需要处理的销售出库单。
5. 确认报价表目录、总结果目录、客户明细目录。
6. 勾选 `生成客户每日明细` 和 `生成客户历史汇总`。
7. 点击 `开始运行`。
8. 运行完成后，先看运行日志是否有错误。
9. 打开总结果表，抽查快递费用是否正常。
10. 打开客户历史汇总表，查看客户消费、收款和余额。

## 12. 不建议做的事情

下面这些操作容易导致结果不准确：

- 不要把报价表和销售出库单放反。
- 不要把报价表目录选成单个 Excel 文件。
- 不要随意修改销售出库单的表头。
- 不要在重量里填写文字。
- 不要删除客户历史汇总表里的 `历史汇总`、`快递明细`、`收款记录` sheet。
- 不要修改 `收款记录` 的表头。
- 不要手工删除 `快递明细` 里的系统隐藏列。
- 不要在软件运行时同时编辑正在生成的 Excel 文件。

## 13. 出问题时先看哪里

优先看软件左侧的 `运行日志`。

日志里通常会告诉你：

- 哪个文件有问题。
- 哪一行有问题。
- 缺少哪一列。
- 哪个业务员找不到报价。
- 哪个快递模板或省份匹配不到。
- 建议你检查哪个报价 sheet。

如果自己看不出来，可以把完整日志复制出来，发给维护人员排查。
