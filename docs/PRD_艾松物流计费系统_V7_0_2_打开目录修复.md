# 艾松物流计费系统 V7.0.2 打开目录修复 PRD

## 背景

V7.0.1 中，底部快捷按钮用于打开生成结果、输出目录和客户目录。实际在 Windows 打包版本中，相关按钮存在失效风险，原因是底层打开逻辑使用了 macOS 专用的 `open` 命令，无法在 Windows exe 环境中工作。

## 目标

1. 修复底部快捷打开按钮在 Windows exe 中无法打开目录或文件的问题。
2. 底部目录按钮必须使用用户在界面中实际设置的目录。
3. 保持 macOS、Windows、Linux 的基础兼容性。
4. 更新版本到 V7.0.2，并让输出文件后缀同步升级。

## 范围

本版本包含：

- 打开选中文件。
- 打开所在目录。
- 打开输出目录。
- 打开客户目录。
- 应用显示版本。
- 结果文件版本后缀。

本版本不包含：

- UI 布局重设。
- 快递费计算规则调整。
- 客户拆分和历史汇总规则调整。

## 功能设计

### 跨平台打开逻辑

根据当前系统选择不同打开方式：

- Windows：使用 `os.startfile`。
- macOS：使用 `open`。
- Linux：使用 `xdg-open`。

### 用户实际目录读取

`打开输出目录` 和 `打开客户目录` 不读取默认目录，而是读取界面当前输入框中的路径：

- 总结果目录：`output_dir_var`
- 客户每日明细目录：`split_dir_var`

如果路径为空，则提示用户先设置目录。

### 目录自动创建

点击目录按钮时，如果目录不存在，系统会自动创建目录后再打开，保持原有易用性。

## 验收标准

1. Windows exe 中点击 `打开输出目录` 能打开用户设置的总结果目录。
2. Windows exe 中点击 `打开客户目录` 能打开用户设置的客户每日明细目录。
3. 点击 `打开选中文件` 能打开结果列表中的 Excel 文件。
4. 点击 `打开所在目录` 能打开选中文件所在文件夹。
5. 界面版本显示为 `V7.0.2`。
6. 生成总结果文件后缀为 `_v7_0_2.xlsx`。
