# 艾松物流计费系统 V7.0.1 品牌升级 PRD

## 1. 背景

现有桌面工具已经完成快递费计算、客户每日明细拆分、客户历史汇总和 macOS 打包。

当前需要把软件从“快递费计算工具”的旧命名升级为“艾松物流计费系统”，作为 V7.0.1 的品牌升级版本。

## 2. 目标

V7.0.1 的目标不是重做算法，而是完成软件壳子和识别信息升级，让用户打开后看到的是一个更正式的物流计费系统。

核心目标：

1. 软件名称升级为 `艾松物流计费系统`。
2. 窗口标题、打包应用名、启动目录、日志目录统一切换到新品牌。
3. 保留原有计费逻辑、报价表读取逻辑、客户拆分逻辑和历史汇总逻辑。
4. 兼容旧配置，让已使用旧版本的用户无需重新设置路径。

## 3. 范围

### 3.1 本期要做

- 修改 GUI 标题文案。
- 修改 macOS `.app` 名称。
- 修改应用支持目录和日志目录名称。
- 修改版本号为 `V7.0.1`。
- 修改总结果输出后缀为 `v7_0_1`。
- 保留旧配置读取兼容。

### 3.2 本期不做

- 不改计算公式。
- 不改报价模板结构。
- 不改客户拆分目录规则。
- 不改规则配置内容。
- 不改输出 Excel 的列顺序和字段。

## 4. 产品信息架构

### 4.1 软件名称

```text
艾松物流计费系统
```

### 4.2 版本

```text
V7.0.1
```

### 4.3 输出文件命名

总结果文件继续沿用批量处理逻辑，但后缀改为：

```text
v7_0_1
```

示例：

```text
【5.1】_销售出库单_快递费计算结果_v7_0_1.xlsx
```

## 5. 界面文案调整

GUI 需要统一替换：

- 窗口标题：`艾松物流计费系统 V7.0.1`
- 页面主标题：`艾松物流计费系统`
- 状态区保留“就绪 / 运行中 / 完成 / 失败”等运行状态

## 6. 系统路径调整

新的本地支持目录：

```text
/Users/beetle/Library/Application Support/艾松物流计费系统
```

新的日志目录：

```text
/Users/beetle/Library/Logs/艾松物流计费系统
```

## 7. 兼容策略

如果新配置目录中没有配置文件，系统会尝试读取旧目录：

```text
/Users/beetle/Library/Application Support/快递费计算工具/config.json
```

这样可以保证品牌升级后，原有销售表、报价目录、输出目录和规则配置尽量自动延续。

## 8. 验收标准

1. 打开软件后，标题显示为 `艾松物流计费系统 V7.0.1`。
2. `.app` 包名和显示名为 `艾松物流计费系统`。
3. 输出结果文件后缀为 `v7_0_1`。
4. 原有路径配置能继续读取。
5. 4.30 和 5.1 批量计算仍可成功完成。
6. 客户每日明细和历史汇总仍可正常生成。

## 9. 建议的下一步

如果品牌升级确认没问题，下一步可以继续做：

- 首页品牌区增强。
- 启动页或 splash。
- 结果摘要和客户总览强化。
