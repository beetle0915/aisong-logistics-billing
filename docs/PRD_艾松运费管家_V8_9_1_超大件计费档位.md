# 艾松运费管家 V8.9.1 超大件计费档位 PRD

## 背景

旧版系统把所有模板都按 `1kg` 首重计算。实际业务中，大件模板的 `首重费用` 不是 1kg 价格，而是大件起始重量以内的首重价格。例如大件起始重量为 `20kg` 时，`22kg` 应按 `大件首重费用 + 2 * 大件续重费用` 计算。

同时业务需要新增超大件档位，默认从 `60kg` 起算，并在系统设置中可维护。

## 目标

1. 保持报价表三列结构不变：`省份参照列`、`首重费用`、`续重费用`。
2. 大件阈值同时作为大件首重重量，默认 `20kg`。
3. 新增超大件规则，默认快递公司为 `顺丰`、`德邦`，阈值和首重重量为 `60kg`，模板后缀为 `_超大件`。
4. 结果表新增 `首重重量`、`计费档位`、`计费模板`，方便复核费用来源。
5. 兼容旧配置文件。旧配置没有超大件字段时，自动使用默认超大件规则。

## 计费规则

系统先识别标准快递公司，再按重量从高到低选择计费档位：

```text
如果标准快递公司属于超大件快递，并且重量 >= 超大件阈值：
    计费档位 = 超大件
    计费模板 = 标准快递公司 + 超大件模板后缀
    首重重量 = 超大件阈值
否则如果标准快递公司属于大件快递，并且重量 >= 大件阈值：
    计费档位 = 大件
    计费模板 = 标准快递公司 + 大件模板后缀
    首重重量 = 大件阈值
否则：
    计费档位 = 普通件
    计费模板 = 标准快递公司
    首重重量 = 1kg
```

续重重量统一按当前档位首重重量计算：

```text
续重重量 = max(ceil(重量 - 首重重量), 0)
快递费用 = 首重费用 + 续重费用 * 续重重量
```

德邦仍保留最终费用四舍五入为整数的规则。

## 系统设置

`系统设置 -> 大件规则` 页面增加超大件配置项：

```text
大件快递
大件首重重量
大件模板后缀
超大件快递
超大件首重重量
超大件模板后缀
```

保存规则时校验：

1. 大件首重重量必须是大于 0 的数字。
2. 超大件首重重量必须是大于 0 的数字。
3. 超大件首重重量必须大于大件首重重量。
4. 大件和超大件快递公司列表不能为空。
5. 大件和超大件模板后缀不能为空。

## 报价表要求

默认需要支持这些 sheet：

```text
顺丰
顺丰_大件
顺丰_超大件
德邦
德邦_大件
德邦_超大件
申通
```

每个 sheet 仍只需要：

```text
省份参照列
首重费用
续重费用
```

如果销售记录命中超大件，但对应业务员报价表没有 `顺丰_超大件` 或 `德邦_超大件`，运行日志明确提示缺少超大件报价模板。

## 输出结果

销售出库单结果追加字段包含：

```text
快递费用
首重费用
续重费用
首重重量
续重重量
计费档位
计费模板
快递公司（标准版）
报价版本
报价生效日期
```

## 验收标准

1. 顺丰 `22kg`，大件首重重量 `20kg`，报价 `首重费用=30`、`续重费用=5` 时，结果为 `40`，续重重量为 `2`。
2. 顺丰 `65kg`，超大件首重重量 `60kg`，报价 `首重费用=80`、`续重费用=8` 时，结果为 `120`，续重重量为 `5`。
3. 缺少 `顺丰_超大件` sheet 时，运行日志提示 `缺少超大件报价模板：顺丰_超大件`。
4. 系统设置保存后重启，超大件快递、阈值和后缀不丢失。
5. 旧配置文件未包含超大件规则时，自动使用默认 `顺丰、德邦 / 60kg / _超大件`。
