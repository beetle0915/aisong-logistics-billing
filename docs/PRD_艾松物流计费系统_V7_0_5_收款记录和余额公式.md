# 艾松物流计费系统 V7.0.5 收款记录和余额公式 PRD

## 背景

当前客户历史汇总表主要用于展示每日快递费用，并额外生成 `按快递公司汇总`、`明细索引` 两个辅助 sheet。实际对客场景中，更需要在同一份客户汇总表里登记客户充值/付款记录，并自动计算累计收款和当前余额。

本版本先实现收款记录和余额公式，不实现逐条快递明细增量追加。

## 目标

1. 客户历史汇总工作簿新增 `收款记录` sheet。
2. `收款记录` sheet 提供固定表头，方便人工录入客户充值情况。
3. `历史汇总` sheet 新增收款和余额相关列，通过 Excel 公式自动计算。
4. 刷新客户历史汇总时保留已有 `收款记录` 的人工录入内容。
5. 客户历史汇总文件名带业务员/客户名称，便于在结果列表中识别。
6. 不再生成 `按快递公司汇总` 和 `明细索引` sheet。
7. 版本号升级为 `V7.0.5`。

## Sheet 设计

### 历史汇总

字段顺序：

| 字段 | 说明 |
| :--- | :--- |
| 日期 | 每日明细对应出库日期 |
| 单数 | 当日快递单数 |
| 总重量 | 当日总重量 |
| 今日快递总消费 | 当日快递费 |
| 累计快递费用 | 截至当日累计快递费 |
| 今日收款 | 从 `收款记录` 按支付时间匹配当日收款金额 |
| 累计收款 | 从 `收款记录` 统计截至当日累计收款 |
| 当前余额 | `累计收款 - 累计快递费用` |
| 顺丰单数 | 当日顺丰单数 |
| 申通单数 | 当日申通单数 |
| 德邦单数 | 当日德邦单数 |
| 大件单数 | 当日大件单数 |

公式规则：

```text
今日收款 = SUMIFS('收款记录'!$D:$D, '收款记录'!$A:$A, ">=" & 当前行日期, '收款记录'!$A:$A, "<" & 当前行日期 + 1)
累计收款 = SUMIFS('收款记录'!$D:$D, '收款记录'!$A:$A, "<" & 当前行日期 + 1, '收款记录'!$A:$A, "<>")
当前余额 = 累计收款 - 累计快递费用
```

### 收款记录

字段顺序：

| 字段 | 说明 |
| :--- | :--- |
| 支付时间 | 客户实际支付日期 |
| 支付方式 | 微信、银行卡、支付宝等 |
| 收款人 | 实际收款人 |
| 已付金额 | 本次收款金额 |
| 收款时间 | 款项确认时间 |

`收款记录` 是人工维护 sheet。系统刷新历史汇总时只补齐表头和格式，不覆盖已有收款数据。

## 文件命名

客户历史汇总文件使用：

```text
业务员名称_客户快递费历史汇总.xlsx
```

例如：

```text
张三_客户快递费历史汇总.xlsx
```

如果客户目录中存在旧版本文件 `客户快递费历史汇总.xlsx`，刷新时会读取旧文件中的 `收款记录`，并写入新命名文件，避免已录入收款记录丢失。

## 非目标

1. 本版本不实现快递费逐条明细总表。
2. 本版本不实现历史记录 ID 和重复导入判断。
3. 本版本不调整 GUI 勾选项。
4. 本版本不改客户每日明细生成逻辑。

## 验收标准

1. 新生成的客户历史汇总文件名包含业务员/客户名称。
2. 新生成的客户历史汇总文件只包含 `历史汇总`、`收款记录` 两个 sheet。
3. `收款记录` 表头为 `支付时间`、`支付方式`、`收款人`、`已付金额`、`收款时间`。
4. `历史汇总` 包含 `今日收款`、`累计收款`、`当前余额` 三列。
5. `历史汇总` 中收款和余额列为 Excel 公式。
6. 已存在 `收款记录` 数据时，刷新客户历史汇总后原有手工收款记录仍保留。
7. 单元测试覆盖新 sheet、公式、文件命名和收款记录保留行为。
