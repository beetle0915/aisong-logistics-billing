# 艾松运费管家 V8.5.3 界面入口和报价预览优化 PRD

## 背景

V8.5.2 已经移除了左侧 `客户档案` 占位入口，并对 `报价预览` 的基础控件样式做了优化。继续使用时发现，界面中仍有几个入口和布局会让用户产生疑惑：

- 左侧侧边栏和 `费用计算` 页面内都存在 `开始计算`。
- `费用计算 -> 配置` 中的 `刷新全部客户历史汇总` 对普通用户风险较高，且不适合作为日常入口。
- `系统设置` 的四类配置仍偏分散，编辑时不够聚焦。
- `报价预览` 的快递公司标签在选中和未选中状态下视觉尺寸不够稳定。
- 报价预览表格只有 3 列，查看大量省份报价时信息密度偏低。

## 目标

1. 版本升级为 `V8.5.3`。
2. 删除 `费用计算 -> 配置 -> 刷新全部客户历史汇总` 可见选项。
3. GUI 层强制 `refresh_all_customers=False`，避免旧配置中曾经保存为 true 后出现“隐藏但仍生效”。
4. `系统设置` 页面改为顶部四个标签：
   - 目录配置
   - 精准映射
   - 关键词映射
   - 大件规则
5. 删除整体左侧侧边栏的 `开始计算` 按钮，保留 `费用计算` 页面内部的开始/重新运行入口。
6. `报价预览 -> 当前客户快递价格信息` 中，快递公司标签选中和未选中保持同一尺寸，只通过颜色区分状态。
7. 报价预览表格由 3 列升级为 6 列，并为每列提供表头。

## 设计说明

### 费用计算入口

`刷新全部客户历史汇总` 不再作为 GUI 选项展示。核心计算和 CLI 仍保留该能力，方便后续管理员或自动化场景使用。桌面 GUI 的日常运行固定不触发全量刷新，避免用户误操作导致处理时间变长。

左侧侧边栏不再提供全局 `开始计算`。用户进入 `费用计算` 后，可以在 `配置`、`运行` 和 `结果` 页使用页面内按钮完成运行或重新运行。

### 系统设置顶部标签

`系统设置` 使用顶部 `Notebook` 标签组织四类配置。点击不同标签后，只展示对应配置内容，底部固定保留 `恢复默认规则` 和 `保存系统设置`。

目录选择仍保持选择后即时保存；精准映射、关键词映射和大件规则仍通过 `保存系统设置` 保存。

### 报价预览

快递公司标签继续使用 `ttk.Notebook`，但固定 tab padding 和 selected expand，使选中/未选中只改变颜色，不改变尺寸。

表格列调整为：

```text
序号
Excel行号
省份
首重费用
续重费用
状态
```

其中 `序号`、`Excel行号`、`状态` 都由 GUI 根据已读取的报价行派生，不改变核心报价读取逻辑。

## 验收标准

1. `APP_VERSION` 为 `8.5.3`，输出文件后缀为 `v8_5_3`。
2. 费用计算配置页只展示 `生成客户每日明细`、`生成客户历史汇总` 两个生成选项。
3. 即使旧 GUI 状态中 `refresh_all_var=True`，桌面 GUI 构建任务配置时也必须传入 `refresh_all_customers=False`。
4. 左侧侧边栏不再显示 `开始计算`。
5. 系统设置页面的四项配置以顶部标签呈现。
6. 报价预览快递公司标签固定尺寸，状态差异只通过颜色体现。
7. 报价预览表格展示 6 列，并保留省份、首重费用、续重费用三个核心价格字段。
