# 艾松运费管家 V8.8.0 离线启动密钥 PRD

## 背景

软件需要增加一个轻量启动密钥功能。使用者打开软件时，先从另一侧工具复制当前密钥，输入正确后才能进入主界面。

这次采用两边单机的离线方案，不依赖服务器、不联网、不做账号体系。密钥协议来自 `key-protocol.md`。

## 协议

- 协议版本：`v1`
- App ID：`aisong-hash-key`
- 时间窗口：`300` 秒
- 算法：`HmacSHA256`
- 编码：`UTF-8`
- 输出格式：`XXXX-XXXX`
- 共享密钥：`AISONG_HASH_KEY_OFFLINE_SECRET_2026_05`

计算消息：

```text
v1|aisong-hash-key|timeSlot
```

其中：

```text
timeSlot = floor(epochSeconds / 300)
```

取 HMAC 结果的大写十六进制前 8 位，并格式化为 `XXXX-XXXX`。

## 验证规则

1. 启动软件后先显示密钥验证框。
2. 用户输入密钥后，系统在本机离线校验。
3. 校验接受当前时间窗口、上一个窗口、下一个窗口。
4. 校验通过后显示主界面。
5. 校验失败时停留在验证框，提示密钥无效或已过期。
6. 用户取消或关闭验证框时，软件退出。

## 用户体验

验证框显示：

- 软件名称：`艾松运费管家`
- 提示：`请输入 5 分钟内有效的启动密钥`
- 输入框：居中输入密钥
- 按钮：`取消`、`验证`

输入支持常见复制格式，例如：

- `1275-2C7C`
- `12752c7c`
- `1275 2c7c`

内部统一格式化为 `XXXX-XXXX` 后验证。

## 自检和打包

`EXPRESS_APP_SELF_CHECK=1` 时跳过启动密钥，方便本地打包自检和 CI 验证。

保留 `EXPRESS_APP_DISABLE_LICENSE_GATE=1` 作为开发调试开关，只用于开发环境。

## 范围外

- 不做联网激活。
- 不做用户账号。
- 不绑定机器码。
- 不保存长期授权状态。
- 不隐藏共享密钥。该方案属于内部轻量校验，不是高强度防破解授权。

## 验收标准

1. `APP_VERSION` 为 `8.8.0`，输出后缀为 `v8_8_0`。
2. 协议样例 `epochSeconds = 1800000000` 生成 `1275-2C7C`。
3. 当前窗口、前一窗口、后一窗口密钥均可通过验证。
4. 错误或过期密钥不能通过验证。
5. GUI 启动时先验证密钥，通过后才进入主界面。
6. 自检模式跳过密钥验证。
