# 艾松运费管家 V8.8.1 启动密钥锁定遮罩 PRD

## 背景

V8.8.0 启动时已经增加离线密钥校验。用户希望打开软件后，主窗口先呈现“被锁定/弱化”的状态，密钥输入框保持清晰，从视觉上更明确地表达“软件已启动，但还没有解锁”。

## 目标

1. 双击软件后主窗口立即可见。
2. 主窗口上方显示锁定遮罩，弱化业务界面。
3. 密钥输入框清晰置顶，并保持模态拦截。
4. 验证通过后移除遮罩，主窗口恢复正常。
5. 取消或关闭密钥框时退出软件。

## 设计

不使用真正的高斯模糊。Tkinter 在 macOS 和 Windows 上做真模糊不稳定，容易影响窗口层级和打包效果。

采用稳定的半透明感锁定层：

- 在主窗口内容上覆盖 `StartupLockOverlay`。
- 遮罩使用浅灰蓝色背景，表达“界面已锁定”。
- 遮罩中央显示软件名和提示文案。
- 密钥弹窗使用 `Toplevel + transient + grab_set + lift + focus_force` 保持清晰置顶。

## 验证流程

```text
启动主窗口
创建锁定遮罩
弹出密钥输入框
密钥通过 -> 删除遮罩 -> 进入主界面
密钥取消 -> 删除遮罩 -> 退出软件
```

## 验收标准

1. `APP_VERSION` 为 `8.8.1`，输出后缀为 `v8_8_1`。
2. 启动门禁会创建锁定遮罩。
3. 密钥验证通过后删除锁定遮罩。
4. 密钥取消后删除锁定遮罩并退出软件。
5. 自检模式继续跳过启动密钥和遮罩。
