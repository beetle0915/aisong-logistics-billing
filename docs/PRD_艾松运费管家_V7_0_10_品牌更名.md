# 艾松运费管家 V7.0.10 品牌更名 PRD

## 背景

当前软件已经从单纯的快递费计算，逐步扩展到客户每日明细、客户历史汇总、历史快递明细、收款记录和余额公式。原名称 `艾松物流计费系统` 偏正式、偏后台系统感，本版本将软件正式名称升级为更贴近业务使用场景的 `艾松运费管家`。

## 目标

1. 软件显示名称升级为 `艾松运费管家`。
2. 版本号升级为 `V7.0.10`。
3. macOS `.app` 和 Windows `.exe` 的生成名称使用 `艾松运费管家`。
4. macOS 和 Windows 打包产物内置 `艾松运费管家` 应用图标。
5. GitHub Actions 生成的 Windows artifact 名称带版本号，并使用新的英文产品标识。
6. 保留旧配置读取能力，避免用户升级后丢失已保存的目录和规则配置。

## 范围

### 本次包含

- 更新运行时显示名和窗口标题。
- 更新输出文件版本后缀为 `v7_0_10`。
- 更新 macOS 打包名称。
- 更新 Windows 打包目录和 exe 名称。
- 新增应用图标资源：
  - `app/assets/app_icon.png`
  - `app/assets/app_icon.icns`
  - `app/assets/app_icon.ico`
- 更新 GitHub Actions artifact 名称。
- 更新 README 中的软件名、版本号和打包文件示例。
- GUI 默认配置读取时兼容旧目录：
  - `~/Library/Application Support/艾松物流计费系统/config.json`
  - `~/Library/Application Support/快递费计算工具/config.json`

### 本次不包含

- 不改变快递费计算规则。
- 不改变客户历史汇总、收款记录和余额公式逻辑。
- 不改变销售表、报价表、输出表字段格式。

## 验收标准

1. 打开软件后，窗口标题显示 `艾松运费管家 V7.0.10`。
2. macOS 打包生成 `艾松运费管家.app`。
3. Windows 打包生成 `艾松运费管家.exe`。
4. macOS `.app` 的 `Info.plist` 配置 `CFBundleIconFile=app_icon.icns`。
5. Windows PyInstaller 打包命令使用 `app/assets/app_icon.ico`。
6. GitHub Actions artifact 名称为 `aisong-freight-manager-v7.0.10-windows`。
7. 批量结果文件名版本后缀为 `v7_0_10`。
8. 单元测试和编译检查通过。
