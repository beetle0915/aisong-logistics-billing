# 艾松物流计费系统 V7.0.4 德邦费用四舍五入 PRD

## 1. 背景

当前系统中，所有快递公司都先按统一公式计算快递费：

```text
快递费用 = 首重费用 + 续重费用 * 续重重量
```

其中德邦和顺丰在重量达到大件阈值时会切换到 `_大件` 报价模板，但最终费用仍按通用小数保留逻辑输出。

现在业务要求针对德邦快递做特殊处理：德邦最终计算出的快递费如果带小数点，需要四舍五入为整数金额。

## 2. 目标

1. 德邦普通模板和德邦大件模板都适用最终金额四舍五入。
2. 只影响标准快递公司为 `德邦` 的行。
3. 顺丰、申通及其他快递公司继续保持现有计费和小数处理逻辑。
4. 版本号升级为 `V7.0.4`。
5. 总结果输出文件后缀升级为 `_v7_0_4.xlsx`。

## 3. 范围

### 3.1 本期要做

- 新增德邦最终费用整数四舍五入规则。
- 更新 GUI 标题和版本显示。
- 更新 macOS 打包版本号。
- 更新总结果输出文件版本后缀。
- 更新当前计费逻辑说明文档。

### 3.2 本期不做

- 不调整德邦的首重、续重、续重重量计算方式。
- 不调整德邦大件阈值，仍为 `重量 >= 20kg` 切换到 `德邦_大件`。
- 不调整报价表格式。
- 不影响客户每日明细和客户历史汇总结构。
- 不实现 V7.0.3 异常日志优化 PRD 中的日志增强能力。

## 4. 规则设计

### 4.1 适用对象

只要销售行解析后的标准快递公司为：

```text
德邦
```

就应用本规则。

这意味着以下两种模板都会生效：

| 场景 | 计费模板 | 是否四舍五入 |
| :--- | :--- | :--- |
| 德邦普通件 | `德邦` | 是 |
| 德邦大件 | `德邦_大件` | 是 |

### 4.2 计算顺序

德邦仍先按当前通用公式计算原始快递费：

```text
原始快递费 = 首重费用 + 续重费用 * 续重重量
```

然后对德邦最终费用进行整数四舍五入：

```text
德邦快递费用 = round_half_up_to_integer(原始快递费)
```

这里的“四舍五入”按业务常见含义处理：

| 原始快递费 | 输出快递费 |
| :--- | :--- |
| `10` | `10` |
| `10.1` | `10` |
| `10.4` | `10` |
| `10.5` | `11` |
| `10.6` | `11` |

### 4.3 非德邦公司

非德邦公司继续使用当前逻辑：

```text
快递费用 = 首重费用 + 续重费用 * 续重重量
```

默认保留 2 位小数。

## 5. 验收标准

1. 德邦普通件最终费用为小数时，输出整数四舍五入结果。
2. 德邦大件最终费用为小数时，输出整数四舍五入结果。
3. 德邦最终费用正好为整数时，输出整数金额。
4. 顺丰、申通不受影响，仍按当前默认小数逻辑输出。
5. GUI 标题显示为 `艾松物流计费系统 V7.0.4`。
6. GUI 页头版本显示为 `V7.0.4`。
7. 批量输出文件名后缀为 `_v7_0_4.xlsx`。
8. macOS `.app` 打包版本为 `7.0.4`。
