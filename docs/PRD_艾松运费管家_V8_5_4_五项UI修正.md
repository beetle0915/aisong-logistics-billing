# 艾松运费管家 V8.5.4 五项 UI 修正 PRD

## 背景

V8.5.3 已经完成系统设置顶部标签、隐藏全量刷新历史汇总入口、报价预览标签尺寸固定等调整。继续试用后发现，报价预览的 6 列含义需要改成左右两组价格信息，费用计算和工作台仍有几个重复入口需要进一步收口。

## 目标

1. 版本升级为 `V8.5.4`。
2. `报价预览 -> 当前客户快递价格信息` 的 6 列改为：
   - 省份
   - 首重费用
   - 续重费用
   - 省份
   - 首重费用
   - 续重费用
3. 报价预览的原始省份价格记录两两合并展示；如果记录数为奇数，最后一行右侧三列留空。
4. 删除 `费用计算 -> 配置` 底部左侧的 `去系统设置` 按钮。
5. 删除 `费用计算 -> 当前系统设置` 面板里的 `去系统设置修改` 按钮。
6. 删除左侧工作台底部的 `打开输出目录` 按钮，保留结果页内的 `打开输出目录`。
7. 左侧 `工作台` 标题字号调大，让侧边栏层级更清晰。

## 非目标

- 不修改计费核心逻辑。
- 不修改报价表读取规则。
- 不修改 Excel 输出字段。
- 不移除结果页里的输出目录入口。
- 不恢复 `刷新全部客户历史汇总` 的 GUI 入口。

## 设计说明

### 报价预览 6 列

核心读取仍保持一条省份报价一条记录。GUI 在展示时把两条省份报价合并成一行，形成左右两组价格列。

示例：

```text
上海市  ¥6.50  ¥0.90  广东省  ¥6.90  ¥1.60
浙江省  ¥7.00  ¥1.20
```

这样可以在同样高度下看到更多省份价格，也符合用户对“6 列”的真实预期。

### 入口精简

费用计算页只保留页面内真正的运行入口：`开始计算`。系统设置入口保留在左侧工作台和顶部主导航中，不再在费用计算配置页重复出现。

左侧工作台底部只保留：

```text
系统设置
打开客户目录
```

结果页的 `打开输出目录` 仍保留，因为它属于计算完成后的结果查看能力。

## 验收标准

1. `APP_VERSION` 为 `8.5.4`，输出文件后缀为 `v8_5_4`。
2. 报价预览列头顺序为 `省份 / 首重费用 / 续重费用 / 省份 / 首重费用 / 续重费用`。
3. 报价预览两条省份记录合并成一行，奇数条最后右侧为空。
4. 费用计算配置页不再出现 `去系统设置` 和 `去系统设置修改`。
5. 左侧工作台底部不再出现 `打开输出目录`。
6. 左侧 `工作台` 标题字号不低于 12。
7. README、版本记录和打包版本同步更新。
