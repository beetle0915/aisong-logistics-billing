# 艾松运费管家 V8.3 账户余额页 PRD

## 背景

V7.0.5 至 V7.0.6 已经在客户历史汇总表中建立 `历史汇总`、`快递明细`、`收款记录` 三个 sheet，并通过 Excel 公式支持累计收款和当前余额。V8.1 至 V8.2.1 已经完成主界面、系统设置和费用计算三步流程。V8.3 将左侧 `账户余额` 从占位升级为可用页面，把客户账本中的余额信息直接展示在软件里。

## 目标

1. 版本号升级为 `V8.3`。
2. 左侧 `账户余额` 可点击进入真实页面。
3. 从客户明细目录扫描每个客户的历史汇总表。
4. 展示账户余额大盘：
   - 累计消费总额
   - 累计收款总额
   - 当前余额合计
   - 欠款客户数
5. 展示客户余额表：
   - 客户
   - 累计消费
   - 累计收款
   - 当前余额
   - 最近日期
   - 状态
   - 文件路径
6. 支持搜索客户、刷新数据、打开客户历史汇总表和客户目录。

## 范围

### 本次包含

- 新增核心只读读取模块，扫描客户历史汇总工作簿。
- Python 侧重新汇总 `收款记录` 的已付金额，避免依赖 Excel 公式缓存。
- 从 `历史汇总` 最后一条有效记录读取最近日期和累计快递费用。
- 在 GUI 中启用 `账户余额` 导航。
- 新增账户余额 KPI、搜索框、余额表和打开文件/目录操作。

### 本次不包含

- 不编辑 `收款记录`。
- 不新增客户档案字段。
- 不做客户详情抽屉。
- 不做自动监听文件变化。
- 不改变历史汇总表结构和公式。
- 不改变费用计算、拆分、历史汇总生成逻辑。

## 数据规则

1. 客户目录来自系统设置中的 `客户明细目录`。
2. 客户历史汇总文件名为：

```text
客户名_客户快递费历史汇总.xlsx
```

3. 累计消费读取 `历史汇总` sheet 中最后一条有效记录的 `累计快递费用`。
4. 累计收款从 `收款记录` sheet 的 `已付金额` 列重新求和。
5. 当前余额使用：

```text
累计收款 - 累计快递费用
```

6. 当前余额小于 0 时，状态显示为 `欠款`；否则显示 `充足`。

## 交互说明

1. 点击左侧 `账户余额` 进入页面。
2. 点击 `刷新数据` 后重新扫描客户明细目录。
3. 搜索框按客户名称筛选表格。
4. 双击客户行或点击 `打开历史汇总表` 打开对应 Excel。
5. 点击 `打开客户目录` 打开选中客户目录。
6. 如果客户历史汇总表缺少必要 sheet 或列，页面继续展示其他客户，并在状态栏提示存在读取问题。

## 验收标准

1. 主界面显示版本号 `V8.3`。
2. 左侧 `账户余额` 可点击进入真实页面。
3. 页面显示 4 个 KPI 卡片和客户余额表。
4. 余额读取不依赖 Excel 公式缓存。
5. 搜索客户名称可筛选表格。
6. 可打开选中客户历史汇总表和客户目录。
7. 现有单元测试通过。
8. `python -m compileall -q app tests` 通过。
9. macOS 打包自检通过。
10. `git diff --check` 通过。
