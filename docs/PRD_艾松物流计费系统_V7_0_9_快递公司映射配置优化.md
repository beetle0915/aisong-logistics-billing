# 艾松物流计费系统 V7.0.9 快递公司映射配置优化 PRD

## 背景

快递公司映射会直接影响系统能否把销售表中的 `快递公司` 转成报价表中的 sheet 名，是计费正确性的核心配置。旧版 `规则配置` 窗口把精确映射、关键词映射和大件规则都平铺展示，业务含义不够直观。

V7.0.9 聚焦优化快递公司映射配置的可理解性，不改变底层计费逻辑和配置保存格式。

## 目标

1. 将规则配置窗口标题改为 `快递识别与大件规则`。
2. 将快递公司映射作为第一屏核心区域，明确表达 `销售表快递名称 -> 报价表 sheet`。
3. 精确映射区域说明格式：`原始快递名称=标准快递名称`。
4. 关键词映射区域说明其为兜底识别规则。
5. 大件规则下移为高级计费规则，避免和快递公司识别混在一起。
6. 不改变现有配置文件结构，已有用户配置继续兼容。

## 设计

规则配置窗口分为三个区域：

```text
核心识别规则：销售表快递名称 -> 报价表 sheet
  1. 精确映射（优先匹配）
  2. 关键词映射（兜底识别）

高级计费规则：大件模板
```

精确映射说明：

```text
把销售表里的原始快递名称，对应到报价表 sheet 名。格式：原始快递名称=标准快递名称，例如 顺丰速运新3=顺丰。
```

关键词映射说明：

```text
用于兜底识别：当原始快递名称包含关键词时，自动识别为标准快递名称。格式：关键词=标准快递名称，例如 顺丰=顺丰。
```

大件规则说明：

```text
达到重量阈值后，系统会使用 标准快递名称+模板后缀 的报价 sheet，例如 顺丰_大件、德邦_大件。
```

## 非目标

1. 不改变快递费计算规则。
2. 不改变配置 JSON 字段。
3. 不新增映射表格增删行控件。
4. 不改变报价表 sheet 命名规则。

## 验收标准

1. 规则配置窗口标题显示为 `快递识别与大件规则`。
2. 映射区域说明包含 `销售表`、`报价表 sheet` 和 `原始快递名称=标准快递名称`。
3. 关键词映射说明包含 `兜底识别`。
4. 大件规则显示为高级计费规则。
5. `恢复默认规则`、保存、取消行为保持不变。
6. 现有测试和配置保存逻辑继续通过。
7. 版本号升级为 `V7.0.9`。
