# 艾松运费管家 V8.10.0 余额上传 PRD

## 版本目标

新增独立侧边栏功能 `余额上传`，用于把指定日期下每个客户的今日快递费消费与今日余额上传到外部接收端。该功能独立于费用计算、账户余额、报价预览和拆分账单，避免影响现有业务流程。

## 功能范围

1. 左侧导航新增 `余额上传`，位置在 `拆分账单` 之后、`系统设置` 之前。
2. 页面提供上传日期输入，用户必须确认日期后才能上传。
3. 点击 `读取数据` 后，从客户每日明细目录下的各客户历史汇总表读取上传预览。
4. 预览表仅展示：客户、今日快递费消费、今日余额、状态。
5. 上传接口地址和上传密钥放在 `系统设置 > 余额上传` 中维护。
6. 上传失败只影响本次上传，不影响本地费用计算、历史汇总和拆分账单。

## 数据口径

### 今日快递费消费

从客户历史汇总表的 `历史汇总` sheet 中读取上传日期对应行的 `今日快递总消费`。

### 今日余额

优先尝试读取上传日期对应行的 `当前余额`。如果单元格是公式且没有缓存值，则在 Python 侧按截止上传日期重新计算：

```text
今日余额 = 截止上传日期累计收款 - 截止上传日期累计快递费用 - 截止上传日期累计异常扣款
```

其中：

- 截止上传日期累计快递费用：来自 `历史汇总` 的 `累计快递费用`
- 截止上传日期累计收款：来自 `收款记录` 的 `支付时间` 和 `已付金额`
- 截止上传日期累计异常扣款：来自 `异常扣款记录` 的 `扣款时间` 和 `额度`

旧文件缺少 `异常扣款记录` 时，异常扣款按 `0` 处理。

### 状态

```text
今日余额 < 0  -> 欠款
今日余额 >= 0 -> 充足
```

## 系统设置

新增 `余额上传` 设置页：

- 上传接口地址
- 上传密钥

上传请求：

```http
POST <上传接口地址>
Authorization: Bearer <上传密钥>
Content-Type: application/json
```

## 验收标准

1. 旧配置文件缺少上传配置时，软件仍可正常启动，上传配置默认为空。
2. 未配置接口地址或上传密钥时，`确认并上传` 不可用。
3. 未读取数据或未确认上传日期时，`确认并上传` 不可用。
4. 读取数据后，摘要和表格能正确展示每个客户的今日快递费消费、今日余额和状态。
5. 上传请求不包含快递明细、地址、运单号等敏感明细，只包含本 PRD 定义的汇总字段。
