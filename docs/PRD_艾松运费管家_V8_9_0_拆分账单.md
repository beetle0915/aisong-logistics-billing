# 艾松运费管家 V8.9.0 拆分账单 PRD

## 背景

当前软件已经支持费用计算、账户余额、报价预览和系统设置。实际对账时，用户还需要把供应商或快递方提供的账单按 `经手人` 拆成多个独立文件，便于分别核对、发送或归档。

用户提供的参考目录为：

```text
/Users/beetle/Desktop/express/拆分账单/5.7日拆分记录
```

该目录中有 4 个待拆分 Excel。每个文件都包含名称精确为 `账单明细` 的 sheet，部分文件还包含 `账单总览`、`月结报告` 等其他 sheet。V8.9.0 只拆分 `账单明细`，忽略其他所有 sheet。

## 目标

1. 左侧导航新增 `拆分账单`，位置在 `报价预览` 下方、`系统设置` 上方。
2. 新增独立 `拆分账单` 页面，不影响费用计算、账户余额、报价预览和系统设置现有流程。
3. 用户手动选择待拆分目录。
4. 用户点击 `开始测试` 后扫描直属 `.xlsx` 文件，并展示文件识别结果。
5. 只读取每个 Excel 中名称精确为 `账单明细` 的 sheet。
6. 忽略 `Sheet2`、`账单总览`、`月结报告` 和其他任何 sheet。
7. 读取所有可拆分 `账单明细` 的共同表头，放入拆分字段下拉框。
8. 默认优先选择 `经手人`。
9. 用户点击 `开始拆分` 后，按所选字段的值生成拆分结果。
10. 输出文件名格式为 `<字段名>_<字段值>.xlsx`，例如 `经手人_艾松电器.xlsx`。
11. 输出目录为输入目录同父级 `原目录名拆分结果【拆分字段：字段名】`。
12. 输出目录已存在时，自动覆盖同名输出文件，不清空整个目录。
13. 页面内提供独立日志管理，展示扫描、拆分、跳过和完成信息。
14. 本版本先本地打包供用户验收，不主动上传 GitHub。

## 页面设计

### 导航

左侧导航顺序：

```text
费用计算
账户余额
报价预览
拆分账单
系统设置
```

页面标题：

```text
拆分账单
```

页面副标题：

```text
按账单明细 sheet 拆分 Excel，支持按经手人或共同字段生成独立账单文件。
```

### 页面区域

页面参考 `费用计算` 的工作台风格，采用三步工作流：

```text
配置
运行
结果
```

#### 1. 配置

配置页包含：

1. `账单目录`
   - 只读路径输入框。
   - `选择目录` 按钮。
   - 输出目录提示：`输出到同父目录：原目录名拆分结果【拆分字段：字段名】`。
   - `共同字段` 下拉框。
   - `同步字段` 次按钮。
   - `开始测试` 主按钮。

2. `待拆分文件`
   - 展示目录测试后的 Excel 文件识别结果。
   - 列：`文件名`、`账单明细`、`数据行`、`字段状态`、`路径`。
   - 状态包括：`可拆分`、`已跳过`、`读取失败`。

选择目录只更新配置，不自动扫描。用户可以点击 `同步字段` 在配置页刷新共同字段和待拆分文件清单；点击 `开始测试` 会读取共同字段并进入运行页。
如果用户已经选择了存在于共同字段中的拆分字段，例如 `省份`，同步字段或开始测试不能自动改回默认的 `经手人`。

#### 2. 运行

运行页包含：

1. `运行状态`
   - 当前状态。
   - `开始拆分` 主按钮。

2. `运行日志`
   - 独立于费用计算日志。
   - 展示扫描、拆分、跳过、输出、异常和完成信息。

点击 `开始测试` 后自动进入运行页。测试完成后留在运行页，`当前状态` 根据用户当前选择的拆分字段动态展示，例如 `已通过按【省份】拆分字段的测试，可进行【开始拆分】`，用户确认后点击 `开始拆分`。

#### 3. 结果

结果页包含：

1. `拆分结果`
   - 展示本次生成结果。
   - 列：`拆分值`、`文件名`、`行数`、`状态`、`路径`。
   - `拆分值` 使用原始单元格中的真实字段值，不从清洗后的文件名反推。
   - `行数` 展示该拆分值实际写入的明细行数量。
   - 操作：`打开输出目录`、`打开选中文件`。

拆分完成后自动进入结果页。

## 拆分规则

### 文件扫描

只扫描用户选择目录下的直属文件：

- 处理扩展名为 `.xlsx` 的文件。
- 跳过隐藏文件。
- 跳过 `~$` 开头的 Excel 临时文件。
- 跳过非文件项目。
- 跳过输出结果目录。

每个 Excel 只处理名称精确为：

```text
账单明细
```

的 sheet。

如果文件没有 `账单明细`，该文件跳过并记录原因：

```text
缺少 sheet：账单明细
```

### 表头

`账单明细` 第 1 行作为表头。

共同表头按所有可拆分文件的 `账单明细` 表头交集计算，顺序跟随第一个可拆分文件。

参考样例共同表头包括：

```text
序号
日期
运单号码
店铺名称
买家备注
备注
商品编码
颜色规格
标准颜色规格
操作人
省份
寄件地区
到件地区
对方公司名称
计费重量
产品类型
付款方式
费用(元)
折扣/促销
应付金额
经手人
服务
寄件人
```

本版本确认拆分字段为：

```text
经手人
```

同时保留下拉框选择能力，后续可按其他共同字段拆分。

### 有效行过滤

一行必须满足以下条件才参与拆分：

1. 不是空行。
2. 第一列不是 `合 计`、`合计`、`小计`、`总额` 等汇总标记。
3. `运单号码` 非空。
4. 所选拆分字段非空。
5. 所选拆分字段不是 `#N/A`、`N/A`、`无`。

样例中的尾部汇总行，例如：

```text
合 计 ... 159985.00
合 计 ... 23885.32
```

必须跳过，不能生成拆分文件。

### 输出

输出目录：

```text
输入目录同父级 / 输入目录名拆分结果【拆分字段：字段名】
```

例如：

```text
/Users/beetle/Desktop/express/拆分账单/5.7日拆分记录拆分结果【拆分字段：经手人】
```

输出文件：

```text
<字段名>_<字段值>.xlsx
```

例如：

```text
经手人_艾松电器.xlsx
经手人_平平（艾松）.xlsx
```

同一个 `经手人` 在多个源文件中存在记录时，生成一个工作簿，工作簿内包含多个 sheet。每个 sheet 对应一个源文件，sheet 名为源文件名去掉 `.xlsx` 后的清洗结果。

输出目录已存在时：

- 自动覆盖同名输出文件。
- 不删除目录中其他文件。

## 输出工作簿格式

首版只保留值和表头，不复制源文件复杂格式、公式、图片、批注、合并单元格和筛选器。

输出 sheet 统一使用轻量格式：

- 第 1 行展示账款金额汇总。
  - `A1` 为 `账款金额`。
  - `B1` 为 `SUM` 公式，对当前 sheet 明细中的 `应付金额` 列求和。
  - 第 1 行使用较大字号和醒目底色，便于客户直接查看需要支付的金额。
- 第 2 行为表头并加粗。
- 从第 3 行开始展示明细记录。
- 冻结到第 3 行，方便查看汇总和表头。
- 从第 2 行开启自动筛选。
- 设置合理列宽。
- 追加两列：
  - `来源文件`
  - `来源行号`

追加来源列用于用户回查原始账单。

## 命名规则

### 输出文件名

文件名需要清洗：

- 替换 `\ / : * ? " < > |`。
- 替换换行和制表符。
- 去掉首尾空格。
- 过长时截断并追加短 hash。
- 如果清洗后为空，使用 `未命名`。

### Sheet 名

sheet 名需要清洗：

- 替换 `[]:*?/\`。
- 限制在 Excel 31 字符以内。
- 过长时截断并追加短 hash。
- 同一工作簿内重名时追加序号。

## 非目标

1. 不拆分 `Sheet2`。
2. 不拆分 `账单总览`。
3. 不拆分 `月结报告`。
4. 不递归扫描子目录。
5. 不保留源文件复杂格式和公式。
6. 不改费用计算、账户余额、报价预览、系统设置的现有业务逻辑。
7. 不上传 GitHub，除非用户验收后另行确认。

## 验收标准

1. 左侧导航包含 `拆分账单`，位置在 `报价预览` 和 `系统设置` 之间。
2. `拆分账单` 页面分为 `配置`、`运行`、`结果` 三步。
3. 配置页包含 `账单目录`、`待拆分文件` 和 `开始测试`。
4. 运行页包含 `运行状态`、`运行日志` 和 `开始拆分`。
5. 结果页只展示 `拆分结果` 表格。
6. 选择目录不会自动扫描，点击 `同步字段` 后刷新共同字段并停留在配置页。
7. 点击 `开始测试` 后读取共同字段并进入运行页。
8. `拆分账单` 页面可以选择目录、扫描文件、显示共同字段、选择 `经手人` 并执行拆分。
9. 扫描只读取 `账单明细` sheet，忽略其他 sheet。
10. 无 `账单明细` 的文件会跳过并显示原因。
11. 样例目录中 4 个 Excel 都识别为可拆分文件。
12. `经手人` 出现在共同字段下拉框中，并默认选中。
13. 点击 `开始拆分` 后生成 `5.7日拆分记录拆分结果【拆分字段：经手人】` 或当前所选字段对应的结果文件夹。
14. 输出文件名采用 `经手人_<值>.xlsx`。
15. 同一经手人跨多个源文件时，一个输出工作簿包含多个 sheet。
16. 汇总行不会生成 `经手人_159985.00.xlsx` 或 `经手人_23885.32.xlsx`。
17. 输出目录已存在时，自动覆盖同名文件。
18. 运行日志显示扫描、拆分和完成状态。
19. 单元测试覆盖核心拆分逻辑、导航入口、GUI 状态和版本信息。
20. 本地打包后的 macOS app 可启动并通过自检。
