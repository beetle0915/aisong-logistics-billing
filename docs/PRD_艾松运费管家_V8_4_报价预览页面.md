# 艾松运费管家 V8.4 报价预览页面 PRD

## 背景

V8.1 至 V8.3.1 已经完成费用计算、系统设置和账户余额主流程。实际使用中，业务员或客户经常需要快速查看自己的报价模板：每个快递公司 sheet 中，不同省份的首重费用和续重费用分别是多少。V8.4 将左侧 `报价预览` 从占位升级为客户报价模板查看器。

## 目标

1. 版本号升级为 `V8.4`。
2. 左侧 `报价预览` 可点击进入真实页面。
3. 用户点击 `同步快递报价表` 后，系统扫描当前报价目录下的 `.xlsx` 报价文件。
4. `业务员` 下拉框显示报价文件解析出的客户/业务员名称。
5. 用户选择业务员后点击主按钮样式的 `搜索`。
6. 页面下方展示当前客户报价表内容。
7. 展示区顶部按报价表 sheet 名生成标签页，sheet 名即快递公司名称，例如 `顺丰`、`申通`、`德邦_大件`。
8. 点击不同快递公司标签后，表格展示该客户在该快递公司下不同省份的发货价格。

## 范围

### 本次包含

- 新增报价目录同步能力，扫描非临时 `.xlsx` 文件。
- 从文件名解析业务员/客户名称，例如 `艾松-快递报价.xlsx` -> `艾松`。
- 读取选中客户的报价 workbook。
- 按 workbook sheet 顺序生成快递公司标签页。
- 每个标签页展示：
  - 省份
  - 首重费用
  - 续重费用
- sheet 缺少必要列时，该 sheet 标记错误，不影响其他 sheet 读取。
- 页面内展示同步、搜索和读取状态。

### 本次不包含

- 不做单票试算。
- 不输入重量。
- 不输入原始快递公司。
- 不展示最终费用。
- 不编辑报价表。
- 不自动生成报价模板。
- 不改变批量费用计算、客户历史汇总、收款记录和余额公式。

## 交互说明

1. 用户点击左侧 `报价预览`。
2. 点击 `同步快递报价表`。
3. 系统扫描报价目录，并将识别到的业务员/客户放入下拉框。
4. 用户在 `业务员` 下拉框中选择客户。
5. 点击 `搜索`。
6. 页面下方显示客户报价摘要：

```text
客户：艾松    报价文件：艾松-快递报价.xlsx    5 个快递公司    省份记录：170 条
```

7. 展示区顶部显示快递公司标签：

```text
顺丰 / 申通 / 德邦 / 德邦_大件 / 顺丰_大件
```

8. 当前标签页表格展示：

```text
省份      首重费用      续重费用
上海市    ¥6.50        ¥0.90
江苏省    ¥6.30        ¥1.20
```

## 错误与空态

- 未选择业务员时点击搜索：提示 `请先选择业务员。`
- 报价目录不存在：提示重新选择报价表目录。
- 报价目录没有 `.xlsx`：提示目录中没有可用报价文件。
- 客户报价文件丢失：提示点击同步后重试。
- 报价文件无法打开：提示确认文件是有效 `.xlsx` 且未被 Excel 占用。
- 某个 sheet 缺少 `省份参照列`、`首重费用` 或 `续重费用`：该 sheet 记录错误，其他 sheet 继续展示。

## 验收标准

1. 主界面显示版本号 `V8.4`。
2. 左侧 `报价预览` 可点击进入真实页面。
3. 页面包含 `同步快递报价表`、`业务员` 下拉框和主按钮样式的 `搜索`。
4. 同步后业务员下拉框包含报价目录中的客户，例如示例文件 `艾松-快递报价.xlsx` 对应 `艾松`。
5. 搜索后展示区按报价表 sheet 名生成标签页。
6. 示例文件中的 `顺丰`、`申通`、`德邦`、`德邦_大件`、`顺丰_大件` 均可作为标签展示。
7. 当前标签页表格展示省份、首重费用和续重费用。
8. 页面不再出现 `试算价格`、`试算条件`、`单票试算`、`最终费用` 或 `续重重量` 等旧试算入口。
9. 现有单元测试通过。
10. `python -m compileall -q app tests` 通过。
11. macOS 打包自检通过。
12. `git diff --check` 通过。
