# 艾松运费管家

本项目是一个本地桌面工具，用于根据销售出库单、业务员、快递公司、重量、省份和快递报价表自动计算快递费用，并生成总结果、客户每日明细和客户历史汇总账本。

当前版本：`V8.9.2`

## 适用场景

- 每天导入一份或多份销售出库单，批量计算每单快递费用。
- 按业务员/客户拆分每日快递明细，方便对账。
- 为每个客户维护一份长期历史汇总表，包含每日消费、历史逐条快递记录、收款记录、异常扣款记录和余额公式。
- 在报价表或销售表数据异常时，通过运行日志快速定位问题。

## 核心能力

- 批量选择销售出库单，一次处理多个 Excel 文件。
- 按业务员读取对应快递报价表。
- 自动识别销售表中的原始 `快递公司`，转换成 `快递公司（标准版）`。
- 支持顺丰、德邦大件和超大件计费模板，大件默认 20kg 首重，超大件默认 60kg 首重。
- 德邦快递最终费用按整数四舍五入。
- 生成总结果 Excel，文件名自动带版本号。
- 按业务员/客户生成客户每日快递费明细。
- 自动生成客户历史汇总表，文件名带业务员/客户名称。
- 客户历史汇总表包含 `历史汇总`、`快递明细`、`收款记录`、`异常扣款记录` 四个 sheet。
- `收款记录` 支持人工登记付款，`异常扣款记录` 支持人工登记扣款，`历史汇总` 自动计算今日收款、累计收款、今日异常扣款、累计异常扣款和当前余额。
- 历史 `快递明细` 按 `出库单号 + 出库日期时间 + 已发货` 增量覆盖，支持手动登记退货/换货记录不被正常发货记录覆盖。
- 运行日志对报价目录、销售表缺列、重量异常、报价匹配异常和大件模板缺失提供明确建议。

## 启动密钥

V8.8.0 起，打开软件会先要求输入启动密钥。V8.8.1 起，主窗口会先显示锁定遮罩，密钥输入框清晰置顶。密钥由另一侧工具按 5 分钟时间窗口生成，格式类似：

```text
1275-2C7C
```

使用方式：

1. 在另一侧工具生成当前密钥。
2. 复制密钥到 `艾松运费管家` 的启动验证框。
3. 点击 `验证`，通过后进入主界面。

软件会接受当前 5 分钟窗口、上一个窗口和下一个窗口的密钥，用于容忍两台设备时间有几十秒偏差。该方案是离线轻量校验，不需要联网。

## 输入文件要求

### 销售出库单

销售出库单必须包含这些列：

```text
出库日期
业务员
快递公司
省
重量
```

推荐保留 `出库单号`，客户历史 `快递明细` 会使用：

```text
出库单号 + 出库日期
```

作为历史记录唯一 key，同 key 后来的记录会覆盖旧记录。

### 快递报价表

报价表按业务员维护，文件名需要能识别业务员，例如：

```text
张三-快递报价.xlsx
李四-快递报价.xlsx
```

每个报价表中的 sheet 名应对应标准快递模板，例如：

```text
顺丰
顺丰_大件
顺丰_超大件
申通
德邦
德邦_大件
德邦_超大件
```

每个报价 sheet 至少包含：

```text
省份参照列
首重费用
续重费用
```

V8.7.0 起支持按业务员文件夹维护报价版本：

```text
快递报价表/
  张三/
    20260501张三-快递报价.xlsx
    20260503张三-快递报价.xlsx
  李四/
    20260502李四-快递报价.xlsx
```

系统会按销售表中的 `业务员 + 出库日期` 自动选择生效日期不晚于出库日期的最新报价版本。旧格式 `张三-快递报价.xlsx` 仍兼容；如果同时存在 `张三/` 文件夹，优先使用文件夹内的版本报价。

## 输出结果

### 总结果

总结果会在销售出库单基础上追加：

```text
快递费用
首重费用
续重费用
首重重量
续重重量
计费档位
计费模板
快递公司（标准版）
报价版本
报价生效日期
```

批量运行时输出文件名示例：

```text
【4.7】销售出库单_快递费计算结果_v8_9_2.xlsx
```

### 客户每日明细

系统会按业务员/客户和出库日期拆分每日明细，目录结构类似：

```text
客户每日快递费明细/
  张三/
    2026-04-07_张三_快递费明细.xlsx
  李四/
    2026-04-07_李四_快递费明细.xlsx
```

### 客户历史汇总

每个客户会生成一份历史汇总表：

```text
张三_客户快递费历史汇总.xlsx
```

包含四个 sheet：

| Sheet | 用途 |
| --- | --- |
| `历史汇总` | 按日期汇总单数、重量、今日快递总消费、累计快递费用、今日收款、累计收款、今日异常扣款、累计异常扣款、当前余额 |
| `快递明细` | 累计客户历史所有逐条快递记录，按 `出库单号 + 出库日期` 去重覆盖 |
| `收款记录` | 人工登记客户付款/充值记录，供余额公式使用 |
| `异常扣款记录` | 人工登记客户异常扣款记录，供余额公式使用 |

`收款记录` 表头：

```text
支付时间
支付方式
收款人
已付金额
收款时间
```

`异常扣款记录` 表头：

```text
扣款时间
额度
备注
```

## 规则配置

GUI 中的 `规则配置` 用来维护核心识别规则、大件和超大件计费规则。

### 快递公司映射

销售表里的快递名称经常不是报价表 sheet 名，因此系统需要映射：

```text
销售表快递名称 -> 报价表 sheet
```

精准映射示例：

```text
顺丰速运新3=顺丰
顺丰陈开专属=顺丰
申通E物流=申通
德邦快递盖子大360小泡货特惠_4=德邦
```

关键词映射用于兜底识别，例如：

```text
顺丰=顺丰
申通=申通
德邦=德邦
```

### 大件 / 超大件规则

默认计费档位规则：

```text
大件快递：顺丰、德邦
大件首重重量：20kg
大件模板后缀：_大件
超大件快递：顺丰、德邦
超大件首重重量：60kg
超大件模板后缀：_超大件
```

系统按重量从高到低选择模板。以顺丰为例：重量大于等于 60kg 时使用 `顺丰_超大件`；重量大于等于 20kg 且小于 60kg 时使用 `顺丰_大件`；小于 20kg 时使用 `顺丰`。德邦同理。

大件和超大件的重量阈值同时也是该档位的首重重量。例如大件首重重量为 20kg 时，22kg 会按 `大件首重费用 + 2 * 大件续重费用` 计算。

## 报价预览

`报价预览` 页面用于查看每个业务员/客户的报价模板。

使用流程：

```text
同步快递报价表
选择业务员
搜索
切换快递公司标签页
```

系统会从当前 `系统设置` 中的报价目录读取 `.xlsx` 报价文件，业务员下拉框来自报价文件名，例如：

```text
艾松-快递报价.xlsx -> 艾松
```

选中业务员并点击 `搜索` 后，下方会按报价表 sheet 名生成快递公司标签页，例如：

```text
顺丰
申通
德邦
德邦_大件
顺丰_大件
德邦_超大件
顺丰_超大件
```

每个标签页展示该客户在当前快递公司下不同省份的发货价格：

```text
省份
首重费用
续重费用
省份
首重费用
续重费用
```

如果报价目录为空、报价文件无法打开，或某个 sheet 缺少必要列，页面会直接显示诊断信息，方便先修报价表。

## 运行日志与排错

运行日志会尽量指出问题位置、原因和建议。V8.5.1 开始，点击 `开始计算` 后会自动切换到 `费用计算 -> 运行`，并在任务执行中实时追加客户可读的阶段摘要和关键里程碑，例如：

```text
阶段 1/5：准备数据，共 3 个销售表
阶段 2/5：计算快递费
进度：正在处理销售表 1/3：销售出库单.xlsx
里程碑：报价读取完成，共 180 条报价
进度：快递费计算已处理 200/1200 行，成功 198 行，异常 2 行
阶段 3/5：生成客户每日明细
里程碑：客户每日明细生成完成，共 86 份，异常 0 行
阶段 4/5：刷新客户历史汇总
进度：客户历史汇总已刷新 12/35 位客户
阶段 5/5：完成，销售表 3/3，成功 3560 行，异常 4 行；生成文件请到「结果」页查看
```

运行日志重点展示当前阶段和处理进度；具体生成文件仍在 `结果` 页查看，日志中不再重复刷出大量文件路径和内部保存动作。

常见错误包括：

- 报价目录为空：提示目录中没有 `.xlsx` 报价文件，并建议重新选择报价目录。
- 销售表缺列：显示缺失列和当前识别到的列。
- 重量不是数字：显示行号、重量原值和修改建议。
- 找不到报价：显示业务员、计费模板、省份、重量，并建议检查对应 sheet。
- 大件或超大件模板缺失：提示缺少 `顺丰_大件`、`德邦_大件`、`顺丰_超大件` 或 `德邦_超大件`。

## 本地运行

进入项目的 `app` 目录：

```bash
cd app
python -m express_app
```

命令行运行示例：

```bash
python -m express_app.cli \
  --sales-file /Users/beetle/Desktop/express/原始数据表/【4.7】销售出库单.xlsx \
  --price-dir /Users/beetle/Desktop/express/快递报价表 \
  --output-dir /Users/beetle/Desktop/express/输出结果 \
  --split-dir /Users/beetle/Desktop/express/客户每日快递费明细
```
